# Retired project history verification

These are historical #1102 artifacts, archived when #3479 retired project commit-history browsing. They are not current acceptance recipes and are not registered as runnable probes. The probe is inert `.mjs.txt` source, so runtime driver discovery cannot mistake it for an active case. Their relative links and selectors describe the old checkout.

Thread run history, review diffs and full-file reads remain active. The current regression is `apps/web/e2e/project-commit-detail.spec.ts`, which checks that project history stays absent while file selection and tasks still work during the staged retirement.
