docs/deploy/tailscale-mobile.md:65:Cairn trusts `Tailscale-User-Login` only for an exactly allowlisted login on the dedicated Unix listener. TCP identity headers are ignored on every address, including IPv4 and IPv6 loopback. Forwarding headers cannot change this boundary. TCP API clients and scripts must send their bearer token; daemon machine endpoints retain their separate machine credentials.
docs/security/agent-isolation.md:34:When using Tailscale Serve, follow [the existing deployment guide](../deploy/tailscale-mobile.md). Configure `CAIRN_TAILSCALE_SOCKET` and point root-run Serve at that Unix socket. TCP headers, including loopback headers, cannot establish identity. The socket must be mode `0600` in a parent directory that is not writable by group or others. Processes sharing the server user and root can still impersonate an identity through the socket; keep untrusted executors under a separate user.
