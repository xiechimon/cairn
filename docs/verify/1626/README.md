## How the states are built

- Info card: `output: 'info'`, phase review, `hasChanges: false`, the changes endpoint returns an empty file set.
- Session messages: one user task row plus one `info-report` system row, the same shape as what the server's `storeInfoReport` persists (`attachmentId`, `attachmentToken` as `![report.md](attachment:team-1/att-report.md)`, `content` as the report body).
- Code card (contrast, no screenshots): `output: 'code'`, the changes endpoint returns one file change, used to assert the merge row is unchanged.
- Theme: the test writes `localStorage['cairn-theme']` before the page loads and asserts `html[data-theme]` matches the expectation.
