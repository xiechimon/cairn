# Model-channel boundary evidence

The offline probe ran on omarchy with Python 3.12.16, Node 24.14.0 and a digest-pinned
Docker image. `result.json` records the exact source digests and assertions.

The task's workspace was writable. The host ruler, cost file, parent-only fixture
credential and Docker socket were unavailable. The host ruler marker was unchanged
after a write attempt. The container had only loopback and failed an external
network request. Its allowed Messages request completed over the mounted Unix
socket; another route returned 403. The parent recorded the fake provider's usage
and synthetic price calculation.

Provider mode was fake. This is model-channel isolation evidence, not a paid
baseline, a complete production-runner comparison, or final grading isolation.
The paired gate remains disabled for real execution until those checks hold.
