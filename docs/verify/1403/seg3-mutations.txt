# #1403 segment 3: mutations (2026-10-22)

Each mutation is applied alone to one source file in p3a. The script then runs pnpm exec vitest run test/pr-seg3.test.ts test/ci-loop.test.ts test/pr-reconcile.test.ts test/pr-merge-api.test.ts (apps/server) and writes the original file back. Byte identity is checked by md5 at the end. Killed = at least one test fails.

## Run 1

The script's summary column misread vitest's 'Failed Tests N' banner, so the per-line verdicts were wrong; the red-test lines were right. By red lines, 21 of 23 mutations were killed. Two survived:
- M11 (review: drop isOwnPull from the dirty/behind condition) was equivalent. The block is reached only when the PR is not foreign, and foreign = hasPullFields && !isOwnPull, so with hasPullFields true the clause was redundant. It was removed. M11 now drops hasPullFields instead, and F25b gained a case with no head.ref.
- M19 (the anonymous required-list read counted once, not twice) survived because F24's per-IP limit of 4 left the review read skipped either way. F24 now uses 5 and asserts that the review PR read is skipped.
