## Stub / duplicate routes

- `POST /api/analytics/first-touch`, `POST /_mp/api/track` — 204 no-ops.
- `GET /api/remote/identity` — returns `{login: null, via: null}` always.
- `GET /api/auth/session` — byte-identical to `GET /api/user/me` (next line).
- `ALL /api/teams/:id/agents` + `/agents/*` — D60 410 stubs. The remaining
  handler file is memory routes only; rename `routes-agents.ts` to
  `routes-memories.ts` (`registerAgentRoutes` → `registerMemoryRoutes`).

`rest.ts` drops the four retired paths. `agent-removal.test.ts` rewrites to
assert 404 on the `/agents*` surface.

## Migration

0206, generated by `pnpm db:generate` after the `schema.ts` edits, then
hand-appended `DROP TABLE IF EXISTS` for the four `legacy_*_backup` tables
(unmanaged by Drizzle — they never appear in snapshots, so the generator
cannot emit their drops).

Failure behavior: `ALTER TABLE … DROP COLUMN` and `DROP TABLE` are atomic per
statement under SQLite; a mid-migration failure leaves the journal pointing
at the last applied file and boot fails loudly, same as every prior
migration. Fresh boots simply create the reduced schema.
