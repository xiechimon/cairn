# Remote Update (`remote-update`) Edge Cases

> Parent contract: [`docs/design/version-skew.md`](../version-skew.md).
> Cross-lane coordination:
> - **`S7` (`remote-update`) owns:** local desktop app bundle updates (`created` updater, `desktop-update:state/check/install`, sidebar `DesktopUpdateButton`, `TurnFailureCard` `"Update Cairn"`, install refusal feedback), and remote-mode IPC / control parity (`own-computer` remote-host suppression + IPC null stub, `offline-page` host switch, credential IPCs).
> - **`S4` (`fix-ag-banner-skew` / `page-shell-capability`) owns:** `window.cairnDesktop.shell` capability descriptor in `preload.ts`, `AntigravityReloginDialog` / `AddAntigravitySubscriptionDialog` / `AddDevinSubscriptionDialog` / `SetupPrompt` / `own-computer` capability-missing `"更新 Cairn"` (`UpdateCairnNotice`), and removing all plain-browser fallback copy (`"在 Cairn 桌面 App 中打开这一页"`, `own-computer-browser-hint`). Plain browsers (`window.cairnDesktop === undefined` without `DESKTOP_SHELL_USER_AGENT`) do not render desktop-only controls.
> - **`S5` (`remote-version`) owns:** probing `GET /api/server/version`, displaying the connected remote server's version in About/Settings/HostPanel, and updating an older remote host via `POST /api/server/update` + `RemoteUpdateBar` (`desktop-update:remote-state` / `desktop-update:remote-retry`).
> - **Boundary on overlap (e.g. both shell and remote server old, or shell old + server newer):** `desktop-update:state/check/install` and `periodicCheck` stay bound to the laptop shell's own `created` updater in both local and remote modes (so `DesktopUpdateButton` and S4's `"Update Cairn"` triggers always update the laptop app), while `RemoteUpdateBar` (`desktop-update:remote-*`) drives updating an older remote host. Neither hijacks or suppresses the other.
