# Runner ↔ Server Claim Edge-Case Matrix (`part = runner-claim`)

> **Parent contract:** [`docs/design/version-skew.md`](../version-skew.md) section 2B
> **Operations:** [`docs/design/runner-claim-operations.md`](../runner-claim-operations.md)
> **Red-on-main baseline:** `origin/main` `7d7ad8f03` with this lane's test files copied in, run on the Mac mini through `mini-test` (run `mac-c8ca23ea5`).

Terms:

- Old runner = protocol `0` without `claimGeneration` (released before `fix-claim-gen-compat`).
- Mid server = a server between `faacecfc5` and `fix-claim-gen-compat`; it demands a claim generation from every runner.
- Current = this lane's build: runner protocol `1` with `claimGeneration`; server floor `MIN_SUPPORTED_RUNNER_PROTOCOL = 0`.
- Remote mode = the desktop app or a launchd runner on one Mac connected to a server on another (the Mac mini). Local mode = the desktop app's embedded server and its own runner on the same Mac.

Each row names one test. "Red on main" is the failure that test shows on `7d7ad8f03`; "guard" means main already behaves this way and the test keeps it.
