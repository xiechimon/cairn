# Motion and texture

The stone is quiet. Motion only says where a surface came from or that something is still working. Anything the user triggers often, and any reply to their own input, is instant. Values come from the motion slots in `src/styles/shadcn.css` (`--dur-fast` / `--dur-overlay` / `--dur-enter` / `--dur-spring` / `--dur-spin` / `--ease-standard` / `--ease-out-expo` / `--ease-out-strong` / `--ease-check-spring`) or the tw-animate-css defaults. A new surface first finds its row in the table below; if none fits, it gets no motion. A new slot must ship with its consumer in the same PR.

- Animate only `opacity` / `transform` / shadow / color, never layout properties (width / height / top).
- Instant, no transition: the press tint (a pressed `Button` keeps its hover fill in the same frame: `active:duration-0` zeroes the colour transition while pressed, and release fades back; only those labelled variants — default, secondary, outline, destructive — then dip their scale to 0.97, while a pressed row, icon button, link or ghost still never moves, because any larger travel would shift the label and its hit area under the pointer, and a pressed control never changes opacity, because the dip fades in and out and reads as a flash on every click), everything under a coarse pointer, drop placement (`dropAnimation` is null, matching the reference sites), sidebar expand / collapse, theme switch (`.theme-suppress` turns transitions off for two frames), the user's own chat message, the composer ring on hover and focus, closing a menu, popover, Select or tooltip (the `[data-closed]` rule in `motion.css`), and the side panel docked beside the page.
- `prefers-reduced-motion`: every keyframe animation shrinks to 0.01ms and loops run once (the site-wide rule in `motion.css`); transitions are untouched except the done check's scale transition (`check-scale`), which cuts to instant.
- Not used: route transitions, list FLIP, cross-column flights, entry animations on new board cards or chat messages (the Growth rows and the first-run entrance are the exceptions: what arrives on an open page grows, history never does), spring easings other than the critically damped `--ease-check-spring` on the done check (bounce stays 0: nothing overshoots).
- Pins: `e2e/color-freeze.spec.ts` pins `--ease-out-expo`.

## Texture (V16)

The ASCII and dither texture components (`SpiralArt`, `SpiralMark`, `DriftField`, `DriftEdge`, `TextureSkeleton`) were retired in #5339; no surface carries texture now (V16). Loading skeletons are flat bars in the final shape (A4). A texture comes back only through a new A/B-checked rule.
