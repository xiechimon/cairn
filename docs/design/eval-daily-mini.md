# Daily Real-Task Eval on Host Timer — plan, 2026-11-27

Prior art: `docs/research/2026-11-22-real-task-eval.md`, `docs/design/eval-gate.md`.

## User scenario

Newcomer first: someone who installed Cairn today never sees, configures, or pays for this runner—it adds zero settings, zero `CAIRN_*` product env vars, and zero dependencies to the desktop or server install path. Only a repository maintainer runs it on a dedicated macOS host via a `launchd` daily timer (`com.xiechimon.cairn-eval-daily`) outside GitHub Actions and outside the CI merge gate (`EVAL_ENABLED` stays `false` for the gate until lane completion is proven).

The 28 `runtime` tasks and 2 `canary` tasks replay against `fauxProvider` (no model credentials needed). Only the 10 `lane` tasks invoke the real Devin CLI using two `0600` local credential files on the host: `$HOME/langfuse/eval.env` (explicitly setting `LANGFUSE_BASE_URL`, `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY` for self-hosted Langfuse v4) and an isolated Devin CLI home (`EVAL_DAILY_DEVIN_HOME`) holding `.local/share/devin/credentials.toml`, referenced from `$HOME/.config/cairn/eval-daily.env`. Every day at 05:00 local time (or on manual `launchctl kickstart`, or upon wake if asleep at 05:00 via macOS `launchd` `StartCalendarInterval`), the runner syncs a clean detached checkout (`EVAL_DAILY_REPO`) to `origin/main`, runs Langfuse `/api/public/health` and Devin auth preflights (failing fast before running trials when either is unavailable), executes the 40-task suite (`28 runtime × 3 + 10 lane × 1 + 2 canary × 1` = 96 trials) with `--require-langfuse` and `--out` inside `$EVAL_DAILY_STATE/tmp/` (never inside the repo), uploads item traces and scores to self-hosted Langfuse, and atomically writes local summary JSON and HTML under `$EVAL_DAILY_STATE`.

Security scope & governance: `eval/harness/lane.ts` passes `--permission-mode dangerous` and `--process-model in-process` to `devin -p` inside a fresh temporary `eval-lane-*` git fixture directory. In CI (`EVAL_ENABLED` currently `false`), it runs in an ephemeral GitHub runner VM; on the scheduled host, it runs under the operator's account inside temp fixture repos (`EVAL_DAILY_DEVIN_HOME` separates Devin session state and credentials from the Cairn daemon, though it is not an OS filesystem sandbox). Although `eval/**` is `humanQueue.evalConfig` in `packages/shared/merge-gate-paths.json`, the repository owner explicitly authorized fixing the 0/1 harness root cause and `fix-bug`/`rename-var` checks in this task while keeping `EVAL_ENABLED=false` (so no active merge gate evaluates itself; CI merges through `push-queue.mjs`, and owner sign-off covers `eval/**` changes).

3. Add daily runner `scripts/ops/eval-daily.mjs`:
   - Refuses `CI` env or missing/unwritable `EVAL_DAILY_STATE` (`exit 2`). Validates `EVAL_DAILY_REPO`, `EVAL_DAILY_DEVIN_HOME`, and loads `EVAL_DAILY_LANGFUSE_ENV`, requiring `LANGFUSE_BASE_URL`, `LANGFUSE_PUBLIC_KEY`, and `LANGFUSE_SECRET_KEY` to be explicitly non-empty.
   - Uses atomic `wx` lockfile `$STATE/lock` (`{ pid, start, startedAt, runId }`) with `processInfo(pid)` from `scripts/owned-process.mjs`, guarded during reclaim by an atomic `wx` mutex `$STATE/lock.reclaim` (`{ pid, start, createdAt }`). Empty/unparseable `lock` or `lock.reclaim` `< 5_000` ms old is treated as active; `>= 5_000` ms old, dead (`processInfo === null`), PID-reused (`start` mismatch), or (`lock.reclaim` age `> 60_000` ms) is cleared/reclaimed. While holding `lock.reclaim`, if `lock` belongs to a live expired owner (`age > EVAL_DAILY_LOCK_MAX_AGE_MS`, default `4 * 3600 * 1000`, matching `pid + start`), the reclaimer sends `SIGTERM` and polls up to 10s (exceeding the owner's internal 1.5s child-stop grace + state write, then `SIGKILL` + 2s) for `processInfo(pid)` to exit; if `EPERM` or still alive, aborts reclaim (releases `lock.reclaim`, writes `$STATE/last-skip.json`, exits `1`). Once gone, if `lock` still exists on disk, re-reads it and aborts (`skipped_locked`/`lock_initializing`) unless its `runId` (or stale corrupt state `>= 5_000` ms old) still matches the inspected owner, before unlinking `lock` and acquiring `wx`. `releaseLock` unlinks `lock` only if on-disk `runId === myRunId`. If a running `eval-daily.mjs` receives `SIGTERM`/`SIGINT`, it stops its active child or health fetch within `1_500` ms (fitting inside the outer `owned-process.mjs` 5s `GRACE_MS`) so it finishes writing `incomplete` + state files before exit when `lock.runId === myRunId`, or exits `1` untouched when `lock?.runId !== myRunId`.
   - Enforces explicit timeouts on every step (`git fetch`: 60s, `git checkout`: 30s, `pnpm install`: 300s, Langfuse `/api/public/health`: 5s via `AbortController`, `devin-env.mjs --check-auth`: 15s, `eval/run.ts`: `EVAL_DAILY_RUN_TIMEOUT_MS` default `7_200_000` ms = 120m to cover 10 × 10m serial lane tasks + overhead; total inner budget ~7610s < outer `--max-runtime-sec 8100` < 4h `EVAL_DAILY_LOCK_MAX_AGE_MS`). Runs all subprocess steps asynchronously via `runOwnedCommand` (`git`/`--check-auth` attached async `spawn`, `pnpm install` and `eval/run.ts --require-langfuse --out <state>/tmp/<runId>.json` via `spawnOwned`, draining both pipes, cancelling on `SIGTERM`/`SIGINT` within `1_500` ms, and mapping timeout -> `124` and signal `result.signal` / stop signal -> `128+N`).
   - Syncs clean `EVAL_DAILY_REPO` (where `git status --porcelain` including untracked files must be empty) via `git fetch -q origin main && git checkout --detach origin/main` (never `git reset --hard` or `git checkout .`), running `pnpm install --frozen-lockfile --ignore-scripts` only when `pnpm-lock.yaml` sha256 differs from `$STATE/lockfile.sha256`. Runs Langfuse health check and synced `devin-env.mjs --check-auth` before `eval/run.ts`.
   - Counts trials (`total = items.length`, `incomplete = items with r.incomplete !== undefined`, `passed = non-incomplete with non-empty scores all === 1`, `failed = total - incomplete - passed`), assigns `status` and exit code per the first-match table below, atomically persists `$STATE/runs/<runId>.json`, `$STATE/latest.json`, `$STATE/history.json` (newest-first cap 60, backing up corrupted `history.json` to `history.corrupt.<ts>.json`, pruning older `runs/*.json` and stale `tmp/`), and `$STATE/index.html` (HTML-escaping `&`, `<`, `>`, `"`, `'` on every dynamic string and filtering banner, history, and trace URLs through `safeHttpUrl` so only `http:`/`https:` become `<a href>` links while other schemes render as escaped `<code>` text, showing per-case scores, scrubbed diagnostics, delta against latest prior run with `items.length > 0` or `— (first run)` when none, clickable Langfuse trace links when `traceUrl` is present or monospace `trace: <traceId>` / `—` when `projectId` is absent).

## Status and exit-code decision table (`scripts/ops/eval-daily.mjs`, first matching row wins)

| Order | Condition | Recorded `status` | Process exit | State files updated |
|---|---|---|---|---|
| 1 | `CI` env set (not `'false'`/`'0'`) or `EVAL_DAILY_STATE` missing/unwritable | (none) | `2` | None |
| 2 | Live non-expired lock (or `<5s` initializing lock) with matching `start` | (none) | `0` | `$STATE/last-skip.json` only |
| 3 | Expired-lock reclaim failed (`EPERM` or process alive after `SIGKILL + 2s`) | (none) | `1` | `$STATE/last-skip.json` only (`lock` untouched) |
| 4 | Interrupted by signal (`SIGTERM`/`SIGINT`) when `lock` is missing or `lock.runId !== myRunId` | (none) | `1` | None (new owner keeps lock and state) |
| 5 | Interrupted by signal (`SIGTERM`/`SIGINT`) during any step while `lock.runId === myRunId`, or `eval/run.ts` timed out (`124`) / killed by signal (`128+N`) | `incomplete` | `1` | `runs/<id>.json`, `latest.json`, `history.json`, `index.html`, own lock released |
| 6 | Missing/invalid `EVAL_DAILY_REPO` / `EVAL_DAILY_DEVIN_HOME`, dirty repo, or `git fetch` / `git checkout` / `pnpm install` failure | `failed` | `1` | `runs/<id>.json`, `latest.json`, `history.json`, `index.html` (no `lockfile.sha256` on install fail) |
| 7 | Missing `$EVAL_DAILY_LANGFUSE_ENV` or any `LANGFUSE_{BASE_URL,PUBLIC_KEY,SECRET_KEY}`, Langfuse `/api/public/health` preflight fails, or synced Devin auth preflight fails | `incomplete` | `1` | `runs/<id>.json`, `latest.json`, `history.json`, `index.html` (suite skipped) |
| 8 | `eval/run.ts` exited with Langfuse exit code `3` (with or without `--out`) | `incomplete` | `1` | `runs/<id>.json`, `latest.json`, `history.json`, `index.html` |
| 9 | `--out` missing or invalid JSON (non-Langfuse crash / `expectedCounts` mismatch) | `failed` | `1` | `runs/<id>.json`, `latest.json`, `history.json`, `index.html` |
| 10 | Valid `--out`, and (`evalExitCode !== 0` or `incomplete > 0` or `total === 0`) | `incomplete` | `1` | `runs/<id>.json`, `latest.json`, `history.json`, `index.html` |
| 11 | Valid `--out`, `evalExitCode === 0`, `incomplete === 0`, `passed === total > 0` | `ok` | `0` | `runs/<id>.json`, `latest.json`, `history.json`, `index.html` |
| 12 | Valid `--out`, `evalExitCode === 0`, `incomplete === 0`, `passed > 0 && failed > 0` | `degraded` | `0` | `runs/<id>.json`, `latest.json`, `history.json`, `index.html` |
| 13 | Valid `--out`, `evalExitCode === 0`, `incomplete === 0`, `passed === 0` | `failed` | `1` | `runs/<id>.json`, `latest.json`, `history.json`, `index.html` |

## Persisted state, readers, and writers

- **Writers**: `scripts/ops/eval-daily.mjs` is the sole writer for `$EVAL_DAILY_STATE/{lock,lock.reclaim,lockfile.sha256,last-skip.json,runs/<runId>.json,latest.json,history.json,index.html}` (written atomically via temp file + `renameSync`; `lock` and `lock.reclaim` created with `wx` `0600`; JSON `0600`, HTML `0644`). `eval/run.ts` writes only to `--out` (`$EVAL_DAILY_STATE/tmp/<runId>.json` under daily runs, `$RUNNER_TEMP/*.json` under CI).
- **Readers**: `eval/compare.ts` and `.github/workflows/ci.yml` read `eval/run.ts` output JSON (`arm`, `items[].{caseId,kind,repeat,scores,comments,incomplete,gate}`). `scripts/ops/eval-daily.mjs` reads `eval/run.ts` output JSON plus `$STATE/{history.json,lockfile.sha256,lock,lock.reclaim}`. The host operator and local review server read `$STATE/{latest.json,history.json,index.html,runs/*.json}`.
