# Band-aid audit, 2026-11-08

ian's ruling of 2026-11-08: cairn must not contain band-aid fixes. A band-aid hides a symptom and leaves its cause in place. This audit lists the existing band-aids so they can be replaced with root-cause fixes. It changes no code.

## Scope and method

- Repo: `origin/main` at `a2e2ebb51`, read from a `git archive` export. No branch was switched.
- Host: `~/.cairn/tools` on omarchy (installed SHA `a3f51c7c6`), live user units under `~/.config/systemd/user`, and their repo mirrors under `scripts/ops/**`.
- Patterns searched: `|| true`, empty and silent `catch` (873 catch sites classified: 87 empty, 407 silent, 379 logging), `.catch(() => …)`, keep-alive and restart policies, watchdogs and sweeps, sleeps, `waitForTimeout`, `retries:`, `.skip`/`skipIf`/`fixme`, baselines and allowlists, `biome-ignore`/`@ts-nocheck`, raised timeouts, interim fix naming in code and in commit subjects since 2026-09-01.
- CI history: all 1,990 `ci.yml` runs from 2026-11-01 09:44Z to 2026-11-08 (302 ended in failure). Failed-job logs were read for every failed run. The earlier failed attempts of 44 runs that later passed on a rerun were also read, since a rerun pass on the same head marks a flake. Limits: `gh run list` caps each query at 1,000 rows, so runs before 11-01 09:44Z are missing. A flake that failed and was never rerun only shows up here if it recurred elsewhere.
- Evidence labels: **measured** means read in a log, file or command output during this audit. **inferred** means derived from measured facts and checkable. **unconfirmed** means a likely cause that was not reproduced.
- "Protected" means the path matches `protected` in `packages/shared/merge-gate-paths.json`: `scripts/**`, `.github/**`, `**/*.config.*`, `docs/spec/**`, `routes-machine.ts`, `services/machine*.ts` and the other owner surfaces. "Eval ruler" means `integration/eval/**` or `.claude/hillclimb/**`, which agents must not edit.
