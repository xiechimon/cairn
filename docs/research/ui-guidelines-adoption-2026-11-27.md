# Adopting Published UI Guidelines and Automating Enforcement (2026-11-27)

Tag convention: `` `实测` `` (verified by reading the primary source first-hand or running a check in this repo), `` `推断` `` (derived from `` `实测` `` facts and recheckable), `` `猜测` `` (unverified).

> Newcomer framing: A first-time Cairn user installs the macOS app (or opens the web workspace), signs in, connects a computer/model provider, and types into the Coordinator composer or Tasks panel without knowing Cairn's internal rules. Adopting these standards directly removes newcomer friction: readable Chinese-English typography with native Mac text rendering, unobscured keyboard focus (`2.4.11`), accessible 24px/44px controls (`2.5.8`), non-drag alternatives for sorting (`2.5.7`), clear native Mac menus/windows/offline feedback, and zero layout jump on load or click.

### Empirical Baseline Gaps in Cairn Today (`` `实测` ``)

1. **Axe runs mostly without WCAG 2.2**: `apps/web/e2e/chief-home-engine-run.spec.ts` already passes `'wcag22aa'`, whereas `apps/web/e2e/a11y-axe.spec.ts:23` (`['wcag2a', 'wcag2aa', 'wcag21a', 'wcag21aa']`) plus 7 other route/popover specs (`schedules-detail`, `chief-home-thread-usage`, `chief-home-thread-automation`, `project-not-found`, `search-syntax-palette`, `thread-pr-panel`, `usage-popover-icons`) omit `'wcag22aa'`. Beyond axe, WCAG 2.2 AA criteria (`2.4.11` Focus Not Obscured, `2.5.7` Dragging Movements beyond keyboard, `2.5.8` Target Size beyond the Tasks checkbox, `3.2.6` Consistent Help, `3.3.7` Redundant Entry) lack automated assertions (`` `实测` ``).
2. **Missing CSS/interaction guards**: `apps/web/src` currently has `0` hits for `touch-action`, `scroll-margin`, `scroll-padding`, `translate=`, and `beforeunload` (`` `实测` ``). `apps/web/src/styles/app.css:1202` sets `overscroll-behavior: none` on `html` outside `@media (pointer: fine)` (`` `实测` ``).
3. **Focus-ring removal leaks**: Active components still use `outline-none` without `--focus-ring`: `apps/web/src/chief/research-report.tsx:141` has `outline-none` with no `focus-visible:` replacement at all, while `apps/web/src/components/thread/task-pr-line.tsx:91` (`CHIP`) falls back to `focus-visible:underline` instead of the `--focus-ring` ring (`` `实测` ``).
4. **Theming & CJK/ellipsis polish leaks**: `apps/web/src/styles/shadcn.css:181` hardcodes `color-scheme: dark light;` globally while `apps/web/src/theme.ts:49-52` updates `meta[name="theme-color"]` without syncing `document.documentElement.style.colorScheme` (`` `实测` ``). Chinese source copy lives in the object keys of `apps/web/src/i18n/en.ts` (3,292 lines) plus inline `t('...')` calls: `apps/web/src/i18n/en.ts` has 11 key-value lines with ASCII `...` (22 `...` occurrences across Chinese keys and English values) instead of `…` and 1 non-URL Chinese key with a halfwidth colon (`` `IP:端口` `` at line 2809), and `apps/desktop/src/app-menu.ts:16` has halfwidth parentheses in Chinese update progress (`` `实测` ``).
5. **Desktop surfaces un-scoped in design rules**: `node scripts/design-rules-for.mjs` covers `apps/web/` and `/tray` (`computers.md`), but has 0 rules matching `apps/desktop/src/` (`app-menu.ts`, `context-menu.ts`, `tray-menu.ts`, `offline-page.ts`, `window-state.ts`, `tray-popover.ts`) (`` `实测` ``). Specifically, `apps/desktop/src/offline-page.ts` lacks `viewport-fit=cover`, explicit `color-scheme`, `100dvh`, `:focus-visible`, `touch-action: manipulation`, and `aria-live="polite"` on the countdown (`` `实测` ``).
6. **Drag-only ordering lacks single-pointer alternative**: `apps/web/src/components/providers/provider-panel.tsx` uses `@dnd-kit` pointer/touch/keyboard sensors without single-click Move Up/Down buttons for WCAG `2.5.7` (`` `实测` ``).
7. **18 `M` rows remain by-hand**: `MEASURED_BY_HAND` in `apps/web/test/anti-slop-foundations.test.ts:152-155` pins 18 rules (`C1`, `C2`, `C4`, `C5`, `C7`, `C18`, `V12`, `V13`, `V15`, `V17`, `V18`, `L1`, `L3`, `L4`, `L6`, `L7`, `T1`, `A2`) with no automated check (`` `实测` ``).
