## 2. State-Change Audit Matrix (Cairn Web/Desktop)

| State Change | Current Reality (`实测`) | Gap / Friction | Target Unified Behavior |
|---|---|---|---|
| **1. Appear / Disappear (Anchored Popups)** | `dropdown-menu` uses `100ms --ease-out-expo`; `popover`, `select`, `tooltip` use `ease` / `ease-linear`, `zoom-in-95`, `8px` (`-2`) slide; `[data-align-trigger=true]` on `Select` has `animate-none`; `mention-inline` uses `ease-out`. | Four curves and mismatched travel distances on the same popup family; tooltip flashes `ease-linear`. | All anchored popups (`dropdown-menu`, `popover`, `select`, `tooltip`, `mention-inline`) share `origin-(--transform-origin)`, `100ms --ease-out-expo`, subtle `scale(0.97→1)` and `4px` max travel; `[data-closed]` stays instant (`animation: none`). |
| **2. Appear / Disappear (Dialogs & Confirmations)** | `DialogShell` bare, `DialogContent`, `AlertDialogContent` use `zoom-in-95` + `duration-200` symmetric in/out with default `ease`; `SettingsDialog` uses `animate-none! duration-0!`. | `0.95` scale on large modals feels exaggerated; exit runs at full enter duration; Settings snaps abruptly on desktop. | Centered dialogs enter at `scale(0.98→1)` over `200ms --ease-out-strong`, exit subtly to `scale(0.99)` over `150ms --ease-out-strong`; Settings gets a zero-shift `140ms` opacity fade so hit targets stay fixed. |
| **3. Appear / Disappear (Drawers, Panels & Floating Controls)** | `SidePanel` under 1100px slides `12px` with `--ease-standard`; `app-drawer` uses `--ease-standard`; `JumpToLatestButton` jumps instantly (`transition-none`); `SelectionBar` & `TasksAddInput` mount instantly; `QueuedCapsules` mounts instantly. | Drawers feel sluggish at start (`--ease-standard`); `JumpToLatest` & `SelectionBar` pop in without context; `JumpToLatest` must still vanish in `0ms` on click (`chief-home-follow-send.spec.ts`). | Drawers & floating `SidePanel` use `--ease-out-strong`; `JumpToLatestButton` plays `jump-enter` (`160ms --ease-out-expo`) on `data-active="true"` while disappearing in `0ms` on `data-active="false"`; `SelectionBar` uses `dock-enter`, `TasksAddInput` uses `row-enter`, new `QueuedCapsules` use `grow-enter`. |
| **4. Move / Reposition (Indicators)** | `SegmentedTabs` defaults `slide = false` and transitions `left/top/width/height` with `--dur-fast ease`; `SegmentedRadio` has no sliding pill; `PhoneTabs` active highlight jumps directly between tabs. | Active pill jumps across tabs/radios/phone bar instead of gliding continuously along the track. | `SegmentedTabs` defaults `slide = !quiet` with `200ms --ease-out-strong`; `SegmentedRadio` adds measured gliding indicator (no initial mount flight); `PhoneTabs` adds compositor-only `translateX` pill (`200ms --ease-out-strong`). |
| **5. Direct Manipulation & Resize** | `SidePanel` `ResizeHandle` calls `setPreview(to)` on every `pointermove`, triggering React re-renders of the entire panel tree on every frame (`side-panel.tsx`). | React reconciliation overhead during continuous drag risks dropped frames in heavy task lists. | Update `--side-panel-w` directly on the panel DOM element and `aria-valuenow` during pointer drag (`data-resizing`), committing to React/storage once on `pointerup` for true 1:1 60fps tracking. |
| **6. Expand / Collapse (Disclosures)** | `TraceCollapse` uses raw `cubic-bezier(0.23, 1, 0.32, 1)` + rotating chevron; `SidebarProjectGroupHeader` swaps `ChevronRight`/`ChevronDown` with instant mount; `FailureMarker` swaps `ChevronDown`/`ChevronUp` with instant mount; `PrCard` swaps height via Base UI without grid transition; `ApprovalCard` raw args & history mount instantly. | Same disclosure interaction behaves five different ways across the app; swapping two chevron SVGs loses spatial continuity. | One shared `Disclosure` pattern (CSS Grid `0fr ↔ 1fr` + `opacity`, `200ms --ease-out-strong`) and single-chevron CSS rotation (`150ms --ease-out-strong`) across Trace, Sidebar groups, PR details, Failure details, Approval details, and Provider connection. |
| **7. Content Swap** | `.text-swap` uses `--ease-standard`; `CheckResultPopover` switches `checking → passed/failed` without transition; `ContextMeterPanel` bar animates `width` (or static). | Diagnostic state transitions snap harshly; progress bar uses layout `width` instead of transform. | `.text-swap` & `.row-enter` use `--ease-out-strong`; `CheckResultPopover` wraps status swap in `text-swap`; `ContextMeterPanel` bar animates via `scaleX` (`400ms --ease-out-strong`). |
| **8. Icon Transitions** | `CopyIconButton` swaps `<Copy>` / `<Check>` instantaneously and keeps tooltip text static unless `copiedLabel` is passed; `MessageToolbar` copy button has zero visual icon feedback (`onCopy` only); `Checkbox` & `DecisionDock` check icons pop in abruptly. | Copying gives weak or missing in-place confirmation; checkbox ticks lack tactile crispness. | `CopyIconButton` and `MessageToolbar` keep both icons mounted and cross-fade (`scale 0.5→1` + `opacity`) using `--ease-check-spring` on the checkmark, defaulting tooltip to `已复制`; `Checkbox` & `DecisionDock` checks animate cleanly on compositor properties. |
| **9. | **10. Press / Hover / Focus** | Labelled buttons dip to `0.97` cleanly; `Switch` thumb uses `150ms` default easing; `TaskRow` menu & `MessageToolbar` hover reveal pop at `opacity` with `transition-duration: 0s` on container; mobile touch shows browser tap highlight flash on Safari/WebKit. | Switch thumb lacks spring-like deceleration; hover toolbars pop sharply; coarse touch flashes browser tap box. | `ToggleSwitch` & `[data-slot="switch-thumb"]` use `200ms --ease-out-strong`; toolbar/row-menu containers fade opacity over `150ms --ease-standard` (keeping inner `<button>` `transition-duration: 0s` for `chat-instant-feel.spec.ts`); `-webkit-tap-highlight-color: transparent` in `@layer base`. |
| **11. Loading / Done / Error** | `typing-hop` rests 60% of each cycle (`app.css:501-512`); `desktop-update.tsx` waterline uses `duration-200 ease-out`; `en.ts` has minor phrasing inconsistencies (`Import failed, please retry.`, missing trailing period on `Could not copy. Try again`). | Typing dots feel hesitant between hops; update waterline uses generic `ease-out`; two feedback strings differ from Cairn's calm register. | Tune `typing-hop` to a smoother continuous wave (`1.1s`); align waterline to `duration-(--dur-overlay) ease-(--ease-out-strong)`; tighten the two `en.ts` copy strings. |

## 3. Adopted Single-Path Motion Language & Gate Compatibility

1. **Curves & Durations (single source in `src/styles/shadcn.css` + `src/styles/motion.css`)**:
   - **Micro-tints & opacity reveals**: `150ms` (`--dur-fast`) + `--ease-standard`.
   - **Anchored popups & tooltips**: `100ms` + `--ease-out-expo`, origin at `--transform-origin`, `scale(0.97→1)` + `<=4px` directional nudge; instant close (`[data-closed]`).
   - **Dialogs, drawers, panels, disclosures, sliding indicators, switch thumbs**: `200ms` (`--dur-overlay`) + `--ease-out-strong`, centered dialogs `scale(0.98→1)` in / `scale(1→0.99)` out (`150ms`).
   - **Celebratory check confirmation**: `--dur-spring` (`600ms`) + `--ease-check-spring` (critically damped `linear()`, zero overshoot).
2. **Gate Compatibility**:
   - `scripts/ui-registry-gate.mjs`: All `pristine` files under `components/ui/` remain untouched (`alert-dialog.tsx`, `dialog.tsx`, `popover.tsx`, `select.tsx`, `switch.tsx`, `tabs.tsx`, `checkbox.tsx`, `collapsible.tsx`). Only `tooltip.tsx` (already `deviated`) is updated, with `scripts/ui-registry.json` re-frozen via `--write`.
   - `apps/web/test/unslop-signs.test.ts`: Zero `transition-all`, zero layout transitions (`width`/`height`/`top`/`left` in new code; `Disclosure` uses CSS Grid `grid-template-rows`), zero overshoot curves, zero `filter: blur()` additions, zero hype/spoken-register copy.
   - `apps/web/test/motion-picks.test.ts`: Preserves `RingSpinner`, `scale: 0.97` press rule, `dropdown-menu` `100ms --ease-out-expo`, `[data-closed]` instant close, `check-scale`, and `first-run-enter`.
   - `apps/web/e2e/chat-instant-feel.spec.ts` & `apps/web/e2e/chief-home-follow-send.spec.ts`: Buttons inside `home-c` and trace cards retain `transition-duration: 0s` and `box-shadow: none`; `JumpToLatestButton` still drops to `opacity: 0` in `0ms` on click.
   - `apps/web/e2e/search-close-flash.spec.ts` & `apps/web/e2e/search-focus.spec.ts`: `SearchPanel` keeps `VIEWPORT_POP_ANIM` + `scale(0.98→1)` settle to `transform: none`.
