#644 全站动效迁移原型 — 现行复刻值 / 方向A（值桥接）/ 方向B（shadcn 默认）

每行一个动效面，三列三种机制取值。现行 = motion.css 复刻参考站的 registry（#73 决定）； 方向A = 迁到 shadcn/tw-animate-css 机制但把复刻值逐条桥进 --tw-duration / --tw-ease / --tw-enter-*，观感与现行完全一致； 方向B = 直接采用 shadcn 生态默认值（更快、更`通用件`的观感），与参考站产生可感知漂移。 全部动画用 Web Animations API 驱动，数值即注释所标；自动循环，也可手动重播。
