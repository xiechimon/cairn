# Coordinator handoff: verbatim request vs rewritten brief (prior art, 2026-11-08)

Question: when an intake or triage layer hands a human's request to a coding agent, does the agent get the human's words verbatim or an AI-written brief? Where does routing data go, how does the agent reach the conversation, and how is the title made?

Evidence labels: measured = read first-hand on the cited page (quotes under 15 words); inferred = derived from measured facts; guessed = not supported by a page read.

## Pattern that fits cairn

Products that put a human request in front of a coding agent (Linear delegation, Copilot, Devin) send the human text as written and keep routing in separate, typed places: XML blocks plus structured fields (Linear), a separate optional prompt (Copilot), typed API fields and stripped control tokens (Devin). Triage AI (Linear) suggests routing beside the text and leaves the text alone. Only the intra-agent case (Claude Code subagents) paraphrases, and its own docs name the cost: details the parent leaves out never reach the child.

For cairn, the Coordinator must pass the owner's words verbatim and add only structured routing fields: project, subtasks that quote the owner's sentences, priority, and dependencies. It must never write a free-text brief that stands in for the owner's text.

## Recommendation

- Carry the owner's message as an immutable `request` block, verbatim apart from removed control tokens (the Devin pattern). The worker prompt renders it first, in its own tagged section (the Linear `promptContext` pattern).
- Put Coordinator output in typed fields only (`project`, `priority`, `dependsOn`, `subtasks[]`). Each subtask has a `quote` that must be an exact substring of the request; reject, with a test, any subtask whose quote does not match.
- Link the conversation and keep it live: give the worker the thread id and deliver later owner messages as appended events (Linear `prompted`, Devin thread sync), not a frozen snapshot (Copilot's documented gap).
- Derive the title from the owner's words, such as the first quoted subtask sentence, trimmed, or fall back to an auto-generated title marked as such (the Devin API pattern). Show routing as reviewable suggestions beside the text (the Linear triage pane), never written into it.
