# Unified test admission research (#3584)
This is test-runner admission, rather than a change to Actions or merge queues. No designated domain row specifically covers it; the two primary projects are Vitest and Playwright. `Measured` means documentation or source read directly, or a command executed in this session; `Inferred` means a conclusion derived from that evidence.
| Source | Mechanism | Trade-off and project fit | Evidence |
|---|---|---|---|
| Vitest 5.0.1 global setup | Measured: setup can return teardown; workers run after global setup, and teardown finishes after tests or at watch-process exit. | Inferred: it can own a test-lifetime lease, but package-local invocations need their own configured setup, and root setup does not precede every project setup. | [Official contract](https://vitest.dev/config/globalsetup), installed `vitest/dist/chunks/index.DzobfTyw.js`, `_initializeGlobalSetup`, `initializeGlobalSetup`, and `runFiles` |
| Playwright 1.63.0 global setup | Measured: setup can return teardown, but `createGlobalSetupTasks` puts plugin setup before user global setup; web servers are plugins. | Inferred: lifetime support is sufficient, admission timing is not. Vite builds and server startup would already compete before admission. | [Official contract](https://playwright.dev/docs/test-global-setup-teardown), [task ordering](https://github.com/microsoft/playwright/blob/v1.63.0/packages/playwright/src/runner/tasks.ts), [web-server registration](https://github.com/microsoft/playwright/blob/v1.63.0/packages/playwright/src/runner/testRunner.ts) |
| Playwright 1.63.0 configuration modules | Measured: ESM configs are loaded with awaited dynamic import; `.ts` uses the enclosing package's module type, and the web package declares `type: module`. | Inferred: module-level awaited admission runs before web-server plugin startup using the public configuration path, without a private plugin or synchronous helper process. | [Loader](https://github.com/microsoft/playwright/blob/v1.63.0/packages/playwright/src/common/configLoader.ts), [import implementation](https://github.com/microsoft/playwright/blob/v1.63.0/packages/playwright/src/transform/transform.ts), [module classification](https://github.com/microsoft/playwright/blob/v1.63.0/packages/playwright/src/util.ts), [web package](../../apps/web/package.json) |
| Existing Cairn queue | Measured: exclusive files, FIFO tickets, dead-PID reclamation, inherited lease reuse and slot-derived ports already exist. CI currently bypasses regardless of directory existence, and holder files store only PID. | Inferred: reuse this implementation, change the CI predicate and diagnostics, and move caller admission into every runner configuration. | [Shared implementation](../../scripts/heavy-slots.mjs), [affected runner](../../scripts/e2e-affected.mjs), [prepush runner](../../scripts/prepush-vitest.mjs) |
| Existing host wrapper | Measured: `cairn-heavy` uses a separate flock pool sized from available memory, capped at six. | Inferred: delegate to the shared implementation to preserve one pool; retain the wrapper's disk-temp policy and exit-code behavior. | [Host wrapper](../../scripts/ops/host/bin/cairn-heavy), [host documentation](../../scripts/ops/host/README.md) |
Measured: installed Playwright loaded both `.mts` and ESM `.ts` configs with top-level await (`pnpm exec playwright test --config=/tmp/heavy-pw-module/playwright.config.ts --list`, printed `CONFIG-TLA-OK`). Inferred: await the shared allocator in every configuration, before webServer builds. Cache the pending Promise across configuration-loader copies; retain the lease until runner exit and verify ancestor ownership before reuse. Remove wrapper acquisition and generated Playwright configs; keep port/build selection in the standard config.
Measured: separate command executions reported different PID namespace identities, yet connected successfully through a filesystem Unix socket. Inferred: `kill(pid, 0)` alone cannot establish foreign-owner liveness. Slots, FIFO tickets and reclaim guards must share one socket-backed owner record and token; ticket names must distinguish equal namespace-local PIDs.
| Primary source | Measured contract | Inferred application |
|---|---|---|
| [Node IPC paths](https://nodejs.org/api/net.html#identifying-paths-for-ipc-connections) | Filesystem Unix sockets support process-local IPC; Linux/macOS pathname limits are approximately 107/103 bytes. | Use a short unique `/tmp` pathname, independent of slot-directory length. |
| [Listening](https://nodejs.org/api/net.html#event-listening), [unref](https://nodejs.org/api/net.html#serverunref), [close](https://nodejs.org/api/net.html#serverclosecallback), [Node 24.14.0 source](https://github.com/nodejs/node/blob/v24.14.0/lib/net.js) | Listening establishes the bound endpoint; unref permits normal runner exit; crashes can leave socket files. | Listen before publishing any record, retain through waiting/holding, close on release and reclaim dead endpoints. |
| [System errors](https://nodejs.org/api/errors.html#common-system-errors) | Missing/refused connections differ from permission and resource failures. | Only ENOENT/ECONNREFUSED authorizes reclaim; other errors fail admission. A successful connection needs no application-level response. |
Coordinator reviewed [the design](../plans/3584-heavy-slot-all-tests.md) before implementation and approved configuration admission, then the namespace extension: one allocator, listen-before-publication, token-safe cleanup, shared liveness for every artifact, namespace-aware inheritance and short socket paths. Runtime tests must prove serialization, dead-owner reclaim, foreign live-owner/ticket preservation, CI absent/present behavior, inherited ownership and normal runner exit. Legacy records retain PID-based reclaim until rewritten; they cannot prove foreign liveness. Never set `TMPDIR` without `CAIRN_HEAVY_SLOTS_DIR`.
