## 1. Cairn's architectural constraints

Before comparing tools in the abstract, Cairn's agent computer imposes four concrete constraints (`实测`):

1. **CDP driver that sends `Runtime.enable`.** Cairn drives the computer browser with `vercel-labs/agent-browser` v0.41.2 (`d52a5e9`), which connects over CDP and unconditionally sends `Runtime.enable` in `cli/src/native/browser.rs` and `cli/src/native/state.rs` (`实测`). Any stock Chromium exposed to `Runtime.enable` leaks CDP runtime side effects to Cloudflare Turnstile, DataDome, and CreepJS unless neutralized in the C++ engine or removed in the CDP client (`推断`).
2. **CDP-to-no-CDP human takeover on one profile.** For sites such as BOSS Zhipin (`zhipin.com`), Cairn closes the CDP browser on takeover and launches a headed browser with **no debugging port** on the same profile directory and fingerprint identity, then hands back via X11 `windowquit` and `--restore-last-session` (`实测`, `docs/design/computer-login-handoff.md`, `apps/daemon/src/computer/cloak-browser.ts`).
3. **Multi-arch Linux guest (`linux-arm64` and `linux-x64`).** Per owner decisions on 2026-11-17 (`agent-computer-cross-platform-2026-11-17.md`), Mac runs a `debian:stable-slim` **arm64** Linux VM under Apple Containerization while Linux (`omarchy`) and future WSL2 run **x86_64** (`实测`). Inside the Mac's Linux VM, the required binary target is `linux-arm64`, not `macos-arm64` (`推断`).
4. **Distribution and licensing.** Cairn's repository is public and ships a desktop app (`实测`). Bundling proprietary binaries or exposing third-party browser control triggers OEM/SaaS clauses on closed-binary engines (`实测`).

## 3. Architectural synthesis: what actually separates winners from losers

1. **JS-injected stealth (`playwright-stealth`, `puppeteer-extra-plugin-stealth`) is dead against modern WAFs (`实测`).** Overriding getters in JS leaves non-native `Function.prototype.toString` descriptors and leaks untouched prototypes in fresh `<iframe>` and `Worker` realms (`实测`, Clearcote & CloakBrowser docs). Only **engine C++ patches** or **unmodified real Chrome with a clean CDP client** survive.
2. **Automation-protocol leaks matter more than exotic fingerprint noise on single-account flows (`实测`/`推断`).** `agent-browser` currently sends `Runtime.enable` (`实测`), and Playwright sends `--enable-automation` unless stripped. Fixing `Runtime.enable` + `--disable-blink-features=AutomationControlled` eliminates the primary automation tell even on stock Chromium (`推断` from Patchright and `agent-browser` source).
3. **Inside a Linux VM (`debian:stable-slim` arm64/amd64), stock Chromium leaks its Linux/Xvfb environment (`实测`/`推断`).** Official Google Chrome has no `linux-arm64` package; Debian `chromium` under Xvfb exposes `Linux aarch64`/`x86_64`, software WebGL (`llvmpipe`/SwiftShader), missing proprietary media codecs, and Linux font metrics. High-friction gates (Cloudflare, DataDome, BOSS Zhipin) score headless/Xvfb Linux Chromium much harsher than a coherent Windows/macOS persona (`推断`). That is why an **engine-patched binary** is justified for the `stealth: true` path.
4. **Among engine-patched Chromium builds in November 2026, `linux-arm64` + CDP + self-serve licensing narrows the field to one immediate binary (`实测`):**
   - `Camoufox` has `linux-arm64` + MPL-2.0 open source, **but no CDP** (breaks `agent-browser`).
   - `Clearcote` has BSD-3 open source + per-site farbling + TLS pinning + CDP, **but no `linux-arm64` binary yet**.
   - `BotBrowser` has `linux-arm64` + Chromium 157 + CDP, **but no self-serve free profile** (sales-gated `.enc` bundles).
   - **`CloakBrowser`** has `linux-arm64` + `linux-x64` + `macos-arm64` + Chromium 156 + CDP (`Runtime.enable` patched in C++) + self-serve free 1-seat BYO key (`实测`).

## 4. Concrete recommendation

### 4.1 For Cairn's agent computer (`apps/daemon/src/computer/`)

1. **Keep the 2026-11-17 dual-path decision (`system Chromium` default + `CloakBrowser` on `stealth: true` with BYO `CLOAKBROWSER_LICENSE_KEY`) for now (`推断`).**
   - It already matches CloakHQ's `BINARY-LICENSE.md` "Dependency listing" carve-out (Cairn ships no binary; the owner supplies their own key and downloads from official channels) (`实测`).
   - It works identically across `omarchy` (`linux-x64`) and the upcoming Mac Linux VM (`linux-arm64`) without rewriting `agent-browser` away from CDP (`推断`).
2. **Harden two real gaps in Cairn's current implementation (high ROI, small diff):**
   - **Close the Linux→Windows font leak on CloakBrowser (`apps/daemon/computer-image/Dockerfile` and guest image recipe):** `cloak-browser.ts` adopts `getDefaultStealthArgs()`'s `--fingerprint-platform`, which defaults to `windows` on Linux (`实测`, `resident-cloakbrowser-2026-11-16.md`), while the Debian guest only installs `fonts-noto-cjk` (`实测`). Add metric-compatible substitution fonts (`fonts-liberation2`, `fonts-crosextra-carlito`, `fonts-crosextra-caladea`) so `Arial`/`Times New Roman`/`Courier New`/`Calibri`/`Cambria` metrics match a Windows persona (`推断`).
   - **Upgrade default stock Chromium's stealth posture (`apps/daemon/src/computer/browser.ts` / `agent-browser` launch args):** Passing `--disable-blink-features=AutomationControlled` on headed Chromium and removing/avoiding `Runtime.enable` in `agent-browser` (using isolated worlds like Patchright/rebrowser) will prevent unnecessary blocks on the default browser so the 1-seat `stealth: true` CloakBrowser is reserved strictly for hostile anti-bot sites (`推断`).
3. **Strategic escape hatch to eliminate license keys and closed binaries (`Single path` medium-term target): Clearcote Open Build (`BSD-3-Clause`).**
   - Clearcote (`clearcotelabs/clearcote-browser`) solves CloakBrowser's four structural weaknesses: **100% reproducible BSD-3-Clause source patches**, **no license server or concurrency cap** on the open build, **per-eTLD+1 Brave-style farbling** (prevents cross-site Canvas/WebGL linking), and **TLS JA3/JA4 pinning** (`实测`).
   - Once Clearcote publishes `linux-arm64` binaries alongside `linux-x64` (or if Cairn builds Clearcote's open BSD-3 patch series for `linux-arm64` + `linux-x64` in CI), Cairn can replace CloakBrowser completely and delete `CloakLicenseCard`, `CLOAK_LICENSE_SECRET`, and proprietary seat handling (`推断`). Code areas that would simplify: `apps/daemon/src/computer/cloak-browser.ts`, `apps/daemon/computer-image/cloak.mjs`, `apps/web/src/chief/cloak-license-card.tsx`, and `packages/shared` secret schemas.
