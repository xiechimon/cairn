# Evidence for Cairn harness self-improvement — 2026-11-28

Question: what can Cairn borrow from empirical agent improvement and benchmark construction without giving a candidate control of its own exam? This is source research, not a run of any reference benchmark. **Observed** means directly read in the linked primary source or in Cairn code; **inferred** means a design implication, not a measured result; **hypothesis** requires a pilot.

| Primary source | Observed mechanism and number provenance | Inferred Cairn trade-off |
|---|---|---|
| Sakana [Darwin Gödel Machine report, §§3–5](https://arxiv.org/html/2505.22954v3) and [team write-up](https://sakana.ai/dgm/) | The coding agent edits the scaffold around a frozen model; downstream tasks score variants, and an archive supplies future starting points. Evaluation is staged. The team documents candidates tampering with signals used to detect unwanted behavior. Published gains are on the authors' stated datasets and protocols, not a Cairn forecast; their SWE-bench headline is not a full Verified score. | Borrow downstream selection and cheap rejection. Given issue text and the pre-fix code, the agent submits a patch. The evaluator requires both fail-to-pass regression tests and pass-to-pass preservation tests. | Reuse Cairn's parent/fix evidence and patch-based grading. Neither a plausible final message nor the mere presence of a patch earns a pass. |
| OpenAI [SWE-bench Verified construction](https://openai.com/index/introducing-swe-bench-verified/) and [official evaluator](https://github.com/SWE-bench/SWE-bench) | OpenAI describes **93** annotators, **1,699** annotated test instances, three annotators per instance, and a released **500**-task subset. The dispatcher separately reported the latest daily run as **12/20** real lane tasks in **85m46s** with `swe-2-high`; that measurement was supplied for this task, not rerun or verified against host artifacts in this lane. One changed result in a 20-case run changes the raw rate by **five percentage points**. Neither the rate nor the wall time measures the end-to-end product or predicts Doubao costs.

## Recommendation

**Inferred:** build a bounded, operator-started search around Cairn's own product path. Exercise the [Coordinator entry](../../apps/server/src/routes-chief.ts) and [daemon runner](../../apps/daemon/src/runner.ts); reuse trusted [snapshot](../../eval/harness/snapshot.ts) and [curation](../../eval/harvest-git.ts) seams where applicable. Score the delivered patch in a separate grader. Retain a declarative policy only after a paired improvement on fixed development confirmation, and test the frozen finalist once on the holdout. The public calibration is separate and reports its exact upstream IDs. These choices borrow SWE-bench/Harbor's separation, AlphaEvolve's restricted search and staged testing, and DSPy's feedback split. They do not depend on assumed gains from any paper. The [design](../design/harness-self-improve.md) specifies boundaries, proving tests and exit criteria.

**Hypothesis:** Doubao DeepSeek V4.1 Flash can drive both roles, and capped isolated concurrency on the mini makes the paired screen practical. Prove both before enabling optimization. The [quota service](../../apps/server/src/services/subscription-quota.ts) reports local activity for Doubao, not provider-reported remaining allowance; there is no price, token-throughput or billed-quota claim here. The candidate lane must consume neither GPT nor Devin quota. Require an externally enforceable allowance or metered budget, not an estimate based on starts.

**Source access:** The agent-reach Jina route was used for first-party public material; where it returned SVG instead of paper text, direct first-party arXiv HTML succeeded. The Exa CLI route was unavailable on this installation and Browser MCP had no connected browser. The Terminal-Bench `/about` and attempted versioned Hub page returned 404; the linked official release/paper, run guide and Harbor spec cover the mechanisms cited. No later task count, live reference-product walk or benchmark reproduction is claimed.
