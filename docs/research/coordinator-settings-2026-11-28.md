## Settings section → UI write route → Coordinator tool

[Project Settings](../../apps/web/src/pages/project-settings-page.tsx) has General and Memory (`?tab=memory`). Schedules sit outside that page registry. No standalone permission page exists. Status is measured against the paths above. “Excepted” is a dispatcher/product policy, not an assertion that every current indirect path already enforces it.
