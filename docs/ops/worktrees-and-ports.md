# Worktrees, ports and heavy slots

Rules for running stacks, tests and worktrees side by side on one host.

- Do not set `TMPDIR` without `CAIRN_HEAVY_SLOTS_DIR`; all lanes must share the heavy-work slot directory.
- Branch from `origin/main`. Create worktrees from the main checkout using absolute paths: `git worktree add "$(git rev-parse --show-toplevel)/.claude/worktrees/<name>" <branch>`.
- Before committing from an older worktree, integrate current `origin/main` and follow `AGENTS.md` and [the host identity migration](agent-bot-identity.md). Git hooks are not installed; run verification explicitly before pushing.
- `E2E_PORT` defaults to 8399; check `lsof -iTCP:8399` before use. If occupied, choose another port and leave its owner running.
- Every heavy entry point waits for a machine-wide slot before it starts: `pnpm prepush`, `pnpm test:changed`, `pnpm test` and every package-local Vitest configuration, Playwright (including `e2e:affected` and shard wrappers), the desktop `build`/`start`/`dist:*` scripts, and the verify-cairn live stack. Capacity is `max(1, floor(cores/4))`, derived from the machine's core count with no override, so an 8-core Mac runs two heavy commands at once. A slot also caps what its holder may spend: a Vitest run gets `max(1, floor(cores/capacity))` workers (`maxWorkers` in every project config) and Playwright the same number of browsers. Admission refuses to start while real CPU utilisation is at or above `CAIRN_CPU_SATURATION_PERCENT` (default 90; `0` disables). Utilisation is sampled from `os.cpus()` deltas, never load average — on macOS load average counts IO waits, so an idle CPU waiting on disk reads as saturation. While saturated the command stays queued and names the measured percentage; after `CAIRN_CPU_SATURATION_MAX_WAIT_MS` (default 10 minutes) it starts anyway and says so. `CAIRN_HEAVY_SLOTS_DIR` selects the shared directory. A Vitest run over at most four named test files is light work: it takes no slot and no worker cap, so a full queue of heavy work cannot hold it up. Waiting output names each holder's lane, pid, command and age, and repeats every 30 s (`CAIRN_HEAVY_QUEUE_REPRINT_MS`); dead holders are reclaimed. Only `CAIRN_HEAVY_GATE_BYPASS=1` skips the queue, and it logs a BYPASS line with its pid and cwd; each workflow sets it once at the top. Keep Python 3 available for admission, and never delete active slot guard files.
- `e2e:affected` delegates admission to Playwright. Its port base is 8398 (direct Playwright: 8399), with stride 10 per slot; `E2E_AFFECTED_PORT` changes the affected base and `E2E_PORT` overrides the base. The configuration selects the leased slot's build directory. Inspect any reported port holder before retrying.
- The verify-cairn live stack (`launch.mjs`) takes the same kind of slot from `live-stack/` inside the shared slot directory before it starts: `CAIRN_LIVE_STACK_SLOTS` defaults to 1; queue output and dead-holder reclaim match the heavy slots. A stack with no connection for `VERIFY_IDLE_TIMEOUT_MS` (default 20 min, `0` disables) stops itself, and one alive for `VERIFY_MAX_AGE_MS` (default 45 min, `0` disables) stops itself too, so a forgotten stack cannot hold the machine's only stack slot.
- Run only one Playwright instance per worktree; shared build output and ports are exclusive. Separate worktrees keep their own build outputs.
- Dev ports default to 5173 and 8787; use `CAIRN_DEV_WEB_PORT` and `CAIRN_DEV_SERVER_PORT` for another stack.
- Start any server, stack or loop that must outlive one command as a background task through `node scripts/owned-process.mjs -- <command>`; it dies with its owner. Never use `nohup`, `setsid`, `disown` or a trailing `&`; `scripts/spawn-ownership.test.mjs` rejects `detached` or `unref()` children outside the helper.
