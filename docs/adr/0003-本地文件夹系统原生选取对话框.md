# ADR 0003 · 本地文件夹选取 = server 代弹系统原生对话框（v1 仅 macOS）

> 状态：**已裁决**（2026-09-29）。
> 来源：新建项目「本地文件夹」选态只能手敲绝对路径的体验问题。本面为**第二个自觉背离 todos.dev 原站**的 UI（原站与 spec 12 均定为「粘贴绝对路径」，无选取面；首个背离见 ADR 0002）。

## Problem Statement

新建项目表单的 local 选态是纯文本输入（`apps/web/src/pages/project-new-page.tsx` 的 `input[aria-label="本地文件夹"]`），macOS 上手敲深目录绝对路径（空格、大小写、层级）痛且易错，撞 400 reason code（`not_absolute` / `not_found` / `not_git`）才发现。诉求：点浏览按钮弹**系统原生**选文件夹对话框（只能选文件夹），选中回填路径。

## 侦察事实（2026-09-29 实测，逐条出处）

| # | 事实 | 出处 |
|---|---|---|
| F1 | web 是无壳纯浏览器 SPA（vite），浏览器安全模型下**拿不到本地绝对路径**：`showDirectoryPicker` 只返回 FileSystemDirectoryHandle（basename，无路径），`webkitdirectory` 只给相对路径；全仓无任何此类调用 | `apps/web/package.json`、全仓 grep |
| F2 | localPath 创建校验发生在 **server 进程 fs**：`validateLocalRepoPath` 三态（isAbsolute / existsSync / isGitRepo）+ `~` 按 server 进程 HOME 展开；实现按**单机假设收紧**，多机「不可见即跳过」降级是已登记未做的后票 | `apps/server/src/services/git.ts:112-149`、spec 12 line 110/118 |
| F3 | localPath 执行时必须在 **daemon 机** fs（claim 下发 cloneUrl=localPath，daemon 本机 clone + conv 分支 push 回用户仓库——#1211：用户主检出的分支/工作树零触碰）；默认部署 server/daemon 同机（loopback），两「必须」重合 | `apps/server/src/services/machines.ts:807-822`、`apps/daemon/src/runner.ts:213-234,552-559` |
| F4 | daemon **无入站面**：纯出站 HTTP 客户端，server→daemon 只有 `{wake, sync, shutdown}` SSE 事件，无通用 RPC——「浏览执行机目录」缺架构前提 | `apps/daemon/src/machine-client.ts`、`routes-machine.ts:225-247` |
| F5 | server 已有「读本机 fs → 投影给 web」先例：skills 现扫（readdir + realpath 逃逸闸 + 容量闸）；无任何通用 `/api/fs` 浏览端点 | `apps/server/src/services/skills.ts:69-116` |
| F6 | server 与 GitOps 缝已有 spawn 本地进程的惯例（isGitRepo = spawn git）；server 默认部署在用户本机（`npx @xiechimon/pacman` → 127.0.0.1:8787），README 同时支持「server 在浏览机、daemon 在构建机」的分离形态 | `apps/server/src/lib/git.ts:201-214`、README.md:28-48 |

## Decision

| ID | 裁决 |
|---|---|
| **D1** | **对话框由 server 进程代弹，不由浏览器弹**（F1 物理约束）：新增 `POST /api/fs/pick` 端点，server spawn `osascript -e 'choose folder'`（macOS 原生 Finder 同款面板，天然只能选文件夹），拿到绝对路径经 HTTP 返回，web 回填 localPath 输入框（输入框仍是真值源，可手改，回填触发既有 basename→项目名逻辑） |
| **D2** | **v1 机器语义 = server 机**：对话框列的就是 server 进程所在机的 fs，与 F2 创建校验同机同语义（选得到 = 提交得过）。执行机（daemon 机）浏览**不做**——被 F4 缺 RPC 缝 + F2 多机降级后票双重阻塞，归该后票同波重估 |
| **D3** | **v1 仅 macOS**：非 macOS / headless / 无 GUI 会话 → 能力探测快速失败，走降级；端点内部留 per-platform dispatch 缝（Linux zenity、Windows PowerShell 将来按需补） |
| **D4** | **降级语义**：探测失败 → 输入框旁一行中性提示（复用 `.prj-new-error` 行家族位置，措辞非错误级：「此部署形态不支持系统对话框，请直接输入路径」）；对话框取消 = 静默 no-op（输入不动、按钮恢复可点）；文本输入永远可用 |
| **D5** | **浏览范围不设白名单**：单租户产品，web 面已是全权控制面（派 build、管密钥），原生对话框本就是全盘视野，不新增实质暴露面。本裁决同样约束后票的应用内浏览器（起始目录 `$HOME`） |
| **D6** | **应用内目录浏览器 = 独立后票**（remote/headless 形态的兜底，非本票范围），已定四件内容契约随票带走：只列目录；每行标 git 仓库（stat `.git`，**提示不硬过滤**——git 判定真值仍是 rev-parse，且父子目录上溯语义存在）；dotfiles 默认隐藏 + toggle；起始 `$HOME`、记住上次位置（localStorage） |
| **D7** | **并发单飞**：同一时刻至多一个 pick 在飞，重复调用拒（409）或复用进行中的对话框——防对话框堆叠 DoS，也是单用户语义的自然表达 |

## Premortem（假设已失败，三种最可能死因 + 护栏）

| 死因 | 护栏 |
|---|---|
| **osascript 弹不出**：server 以 launchd/nohup/ssh 会话跑，无 Aqua session，`choose folder` 报错或弹在无人看的会话里 | 能力探测先行（快速失败，秒级），失败即走 D4 降级；探测方式与「server 从终端起 vs 后台起」两态都要实测（dev 栈 tsx watch 形态尤其） |
| **HTTP 长挂被掐**：osascript 阻塞到对话框关闭，请求可能挂数分钟；dev 栈 vite proxy 对长挂请求的超时行为未验（strictPort 同款「dev/prod 行为分叉」坑族） | 施工期第一颗雷实测 proxy 超时；若被掐则改异步形（spawn 即返 pick id，web 轮询/SSE 取结果），端点契约为此留形 |
| **回填路径仍撞 400**：原生对话框选中的目录不是 git 仓库（对话框不判 git），提交吃 `not_git` | 不新增前置校验——既有 reason code 错误行已分译到「不是 git 仓库」级；D6 后票的 git 标记才做选取时提示；本票接受「选了非 git 目录 → 明确报错」为合格体验 |

## Consequences

- **正向**：主形态（server = 用户 Mac）拿到真原生对话框体验（收藏侧栏、⌘⇧G、hidden files toggle 全是系统自带）；零新 UI 家族（一个按钮 + 既有输入框）；`/api/fs/pick` 的 platform dispatch 缝为将来 Linux/Windows GUI 用户留位。
- **负向**：remote/headless 形态（server 在 VPS）本票交付为零（维持纯输入现状，D6 后票才兜底）；平台分叉自本票始（此前 web 面平台无关）；server 新增「在宿主机弹 GUI」的能力，信任模型按单租户成立，**多租户化时此端点必须重审**。
- **与原站关系**：第二个自觉背离面（ADR 0002 之后）；spec 12 的「粘贴绝对路径」仍是兜底真值通道，背离的是「唯一通道」。
- **重开触发**：多机校验降级后票落地（执行机浏览语义可判定，D2 重估）；出现 Windows/Linux GUI 部署的真实用户（D3 扩平台）；任何 Electron/Tauri 壳决策（F1 前提消失，本 ADR 整体作废重选）。
