# ADR 0013 · 总管面板形态 = 悬浮窗（Multica 式，superseding ADR 0004）

> 状态：**已裁决**（2026-10-08，grill 十三问全收敛，用户逐题定案）。
> 替换：ADR 0004（贴右竖板，2026-09-30 裁决）——0004 重开触发第一条「要做开态持久化」命中，且其动机来源 #447 用户反馈（「面板不应悬浮」）被同一用户反转。
> 修订（2026-10-21，#1428）：D2 里「阴影对齐 Multica `--floating-shadow` 双主题值」不再成立——`--floating-shadow` 改为 `tokens.css` 三档梯里 e3 的池（总管窗与对话框同档，暗色多一条 `--top` 顶部高光），窗自带的 `--edge-ring` 不变；D2 其余几何（380×600、8px 角距、12px 圆角、不透明卡底）照旧。
> 几何正典源：**Multica「悬浮聊天窗」**（`multica-ai/multica` main 源码实测，2026-10-08 浅克隆直读；wiki [[Multica 悬浮聊天窗实现事实]]）。**不是** todos 原站的 418 内缩卡——原站几何（0004 F1）只作考古，不作正典。

## Problem Statement

ADR 0004 把总管面板从悬浮卡改成贴右竖板，动机是 #447 用户反馈「面板不应悬浮，应平铺弹出」——浮层会覆盖内容。平铺的代价是一整套让位机制：内容列 flex 收窄（0004 D2）、detail 路由顶掉 488px 右栏（D7）、board 280px 护栏 + 横向滚动（D8），外加五个壳级挂载点与 detail FAB 特例位（F5）。

八天后同一用户裁决反转：**让位代价大于覆盖代价，且对齐 Multica 形态语言**。悬浮窗回归覆盖层，但是无模态的——不锁页面、不抢焦点，不点它就不打扰；被盖住的内容靠右下角 clearance 让位与 ⌘J 即关消化。让位三特例、五挂载点、FAB 特例位随形态一并退役。

具体例子（为什么让位代价大）：detail 路由上，418 竖板无位可站，0004 只能裁「顶掉右栏格位（互斥）」——用户在右栏看方案文档和跟总管说话二者只能得其一；board 上让位后四列 281→280px 下限 + 横向滚动，「卡不见了」的观感要靠护栏和滚动条披露去解释。悬浮窗把这类结构性特例全部消掉。

## Decision

| ID | 裁决 |
|---|---|
| **D1** | **形态唯一 = 悬浮窗**：无模态浮动卡窗，锚内容区右下角。贴右竖板形态删除；0004 D2（flex 让位）、D6（四壳适用面）、D7（detail 顶右栏）、D8（board 280 护栏）**整体退役**——覆盖层无让位。全站五路由同一形态，无路由特例。 |
| **D2** | **几何皮肤整套采 Multica 原值**（F1）：默认 380×600；距内容区右/下各 8px；圆角 12px；不透明卡底、非玻璃无 blur；阴影对齐 Multica `--floating-shadow` 双主题值。不混 todos 418 内缩卡遗产值。token 槽位工程面定（`--chief-shadow` 改值 vs 新 token；12px 圆角不用 #983 退役面的 `--radius-popover`，落点随 A0 记票）。包含块 = 侧栏右侧内容区，不压侧栏。窄窗/移动端不做特殊形态（Multica <768px 全屏面板不抄；detail-narrow 既有纪律照旧），需要时另票裁。 |
| **D3** | **关闭模型对齐 Multica**（F2）：Minimize 钮（Minus 图标，最小化心智，无 X）+ ⌘J/Ctrl+J；**无 Esc 关、无外点关**（外点本就不关，F6）。Esc 只收面板内层弹层（主题切换器、模型 popover），**永不关面板**——现状「Esc 分层第二按关抽屉」契约作废。**自觉背离** #168 dialog 家族关闭律（X/Esc/backdrop 三路），照 #443 背离先例记此行：悬浮窗是非模态常驻伴侣面，不是模态对话族成员。⌘J 守卫律保留（面板外输入态吞键，F6；不学 Multica 的 allowInEditable）。 |
| **D4** | **FAB**：窗开 = FAB 不渲染（互斥；几何必然，Multica 同律）。全站统一右下角，**detail 特例位（right 504/bottom 104）随 D7 退役**。FAB 几何对齐 Multica 40px / 8px inset（替换 48×48/16px 旧族律——与窗同角同心，「窗从 FAB 长出」的动画心智成立）。#443 unreadOnly 家族差异属行为面，保留。 |
| **D5** | **开态持久化**（0004 D9 反转，重开触发第一条命中）：`isOpen` 存 localStorage，key 纪律照侧栏 `pacman.sidebar-collapsed` 先例（`pacman.chief-open`）；**默认 = 关**（Multica "never pops uninvited" 同律）。尺寸持久化不存在（D8 固定尺寸）。 |
| **D6** | **挂载架构 = 根 layout 单实例常驻**（Multica 同律）：5 挂载点（F5）全退役，收敛为 layout 级单挂；board 内联特例与 detail 拆挂特例消失。**关闭不卸载**：opacity 0 + scale 0.95 + `inert` + `aria-hidden` 常驻挂载，草稿/滚动/线程态全保；「关」的可观测契约从「不在 DOM」改「在 DOM 但 inert」，e2e count-0 断言族按 0012 D6 载体重钉（行为语义不变：关了不可见、不可交互、热键守卫照旧）。工程前提（有无共享 layout route）A0 开工验证，无则新建。 |
| **D7** | **动效**：进出场 = fade + scale 0.95→1，`transformOrigin: bottom right`（窗从 FAB 角长出）——shadcn/Base UI 默认家族，与 Multica 实测值同族（F2），零自定义曲线（ADR 0009 收敛律）。0004 D4 的 translateX 滑入退役。`prefers-reduced-motion` 降级照既有全站法。 |
| **D8** | **尺寸能力分票**：A0 固定 380×600；拖拽 resize（三把手）+ 90% 展开钮另票（0004 D5「拖拽调宽另票」纪律延续）。 |
| **D9** | **行为契约不动面**：线程切换、composer、模型选择、rewind、焦点律、N 裸键、深链（`?chief=<threadId>` / `?chief=settings`）、齿轮可达性（#615：board 内容交换 / 非 board 深链导航）全部原样。设置面承载不变（不进悬浮窗）。窗头钮集合 = 现状（主题 chip、新主题、齿轮、Minimize）；展开钮随 D8 另票。 |

## Premortem（假设 A0 已失败，三种最可能死因 + 护栏）

| 死因 | 护栏 |
|---|---|
| **挂载上提拆坏五壳**：单实例常驻后某个壳的包含块/z/布局撞上（board 包含块是视口 0004 F4、detail-body 是 flex 行、board 内联 FAB 有自己的挂载逻辑），出现「窗压侧栏」「窗被壳裁切」一类位形错 | A0 第一步 = 五路由位形 smoke（每路由一张窗开截图 + boundingBox 断言）+ z-ladder.spec 重钉；包含块统一为根 layout 的内容区，逐壳验收 |
| **inert 常驻破可及性与热键语义**：屏幕阅读器/键盘导航读进 inert 面；hotkeys.ts 的 `closest('.chief-drawer')` 输入态守卫随类名/结构漂移失灵；count-0 断言族重钉时把行为语义一起改掉 | `inert` + `aria-hidden` 双保险是标准语义；重钉清单逐条过 #921 人审 diff（D11）；hotkeys 126 条断言全绿是 A0 合并门 |
| **八天后第二次反转**：悬浮窗盖住看板操作面，用户遇到「卡住我要看的列」又怀念让位版——本 ADR 的动机段就是上一次反转的实录 | 动机与代价双向记录在案（覆盖代价回归是 D1 的固有代价，消化手段 = 无模态 + ⌘J 即关 + clearance 让位）；重开触发写明；形态唯一（D1）不给双形态回潮留缝 |

## Consequences

- **正向**：让位三特例（D2/D7/D8 of 0004）+ 5 挂载点 + detail FAB 特例位 + board 内联特例整体退役，是净删代码；常驻体验（草稿/滚动/开态跨页跨刷新）完整；形态语言对齐 Multica；「窗从 FAB 长出」的角锚动画心智成立。
- **负向**：覆盖代价回归——面板开着时右下角内容被盖（clearance 让位 + ⌘J 即关消化，但固有）；Esc 背离一条（D3，记录在案）；FAB 几何族律改值，chief-fab.spec 20 条 + shell-consistency.spec 27 条重钉；「关 = inert 在 DOM」对 e2e 与 a11y 是新契约，重钉面比纯几何改动宽。
- **与 todos 原站关系**：原站面板本就是悬浮卡（0004 F1），本次回到浮层大类但几何全套从 Multica——背离面计数不变（仍是第 3 个自觉背离面，背离对象从「浮层形态」换成「原站几何值」）。
- **与 #980 图关系**：A0 段的探针重钉与 A1 的 chat 原语装件共享同一份新鲜侦察账（`probe:dump` 开工重跑，#913 旧行数账作废律照旧）。

## 重开触发

- 拖拽 resize / 90% 展开钮另票落地时（D8，尺寸持久化随其裁决）；
- Multica 上游改悬浮窗形态（本次的几何正典源变化）；
- 移动端 / <768px 特殊形态需求出现（D2 明确不做的那块）；
- 挂载架构再变（根 layout 单实例被更大的壳重构顶掉）。
