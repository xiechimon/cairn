## Problem Statement

Before 2026-10-05, the site's visual canon chain was: spec/16 "pixel discipline" — per-domain migration is a **structure-only** change with zero visual re-pinning, and per-face rules remain the canon for geometry and color (policy 4 of #411 merged with the #435 value-canon line); #813 had just finalized the color surface under it (V2 + Herdr purple, contrast re-measurement finalization + fixture baseline sealed). Rollout progress: B1 overlay family, B2 warm-up + resources had landed; B3/B4 not started; 8266 lines of per-face CSS in the tree; 26 components in `components/ui/` already in place.

The problem: the endpoint of structure-only migration is **an old face on a new skeleton** — the visual ceiling is locked to the old face by the pixel discipline, while the 8266 lines of per-face CSS play the roles of both "canon" and "debt" at once. If color, geometry, and CSS debt were moved separately, each would need one construction round plus one e2e re-pinning round. The user's four decisions on 2026-10-05 changed the destination: overhaul in one pass — hue re-selected together with Herdr purple, geometry unfrozen from the status quo, all per-face CSS migrated into Tailwind and zeroed, execution carried directly by the #908 map.

All three ADR conditions are met (recognized by the #911 ticket): **hard to reverse** = site-wide visual re-pinning (2190 pinned points / 101 specs); **surprising without context** = the pixel discipline was still the canon last week, referenced by many tickets including spec/16 and #411/#421/#435/#813; **a real trade-off** = structure-only migration vs free redesign; the #909 three-direction sandbox (A graphite colorless / B teal-ink / C paper-orchid) was the real option set presented to the user, and the user picked C after live review.

## Terminology

The canonical definitions of five terms land with this ADR (specified by the #910 decision / #911 ticket):

- **Semantics-first two-tier system**: the e2e pinning-carrier strategy. Tier 1 = role/label/text semantic locators (`getByRole` first) — the only anchor that stays stable across structures under a free geometry redesign; tier 2 = `data-testid` only for semantic blind spots (containers with no role, pure structural hooks — the 63 zero-CSS-rule pure test hooks measured by #411 are exactly this kind; expected scale <100, not a 1:1 migration of the 522 classes); `data-slot` is internal shadcn component structure that drifts with upstream upgrades — allowed only as an intra-component positioning aid, never pinned by specs.
- **Behavior assertion**: assertions pinning unchanged semantics — text content, element counts, visibility, disabled/checked states, navigation jumps, keyboard interaction sequences. The overhaul switches only their locators; assertion semantics change byte-for-byte nowhere. State-type assertions (semantic classes like `.is-active` / `.selected`) belong to behavior assertions; their carriers switch to `aria-*` / `data-state` (a shadcn built-in convention).
- **Visual assertion**: assertions pinning visual presentation values — `getComputedStyle` values, `boundingBox` geometry, presentational `toHaveClass`, color/radius/spacing/font-size numbers. At overhaul time each is rewritten wholesale against the new canon, with values taken from the #912 canonical table + the c.css finalized palette.
- **With-the-change**: the re-pinning timing strategy — each domain's construction batch completes the spec locator carrier-switch and visual baseline re-pinning **within the same PR**; the rewriter faces the new DOM end-state once and finishes in one pass; no laying hooks first (laying hooks against a dying old DOM = doing it twice), no post-hoc pinning, main never red.
- **Probe dump**: the mechanical method for visual re-pinning — the tool runs on the fixture stack, collects actual values at the existing spec probe points (computed-style / boundingBox) into JSON, and generates an "old baseline value (parsed from spec inline assertions) → new measured value" comparison table; **human diff review** separates expected drift (new canon) from suspected regressions, after which spec inline values are rewritten in batch. Tool construction = #921.
