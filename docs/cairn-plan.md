# Owner decision table (cairn-plan)

Retired. Decisions are written where an agent reads them, not numbered here.

This file used to hold numbered rows (`D…`). The table was empty, and the rows it would have held live in a machine-local plan that contains secrets and quota details, so they were never copied in. A citation such as D114 points at nothing an agent can read. When you touch a file that cites a `D…` id, replace the id with the ruling it names, or delete the citation if the surrounding sentence already states the ruling.

Ticket-scoped design and implementation plans stay under `docs/plans/`. Runtime step handoff plans stay under `$CAIRN_HOME/plans/` and must not be committed from a checkout.
