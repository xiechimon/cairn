# Owner decision table (cairn-plan)

Canonical, git-tracked copy of the owner's plan decision table for cairn.

Record product and process rulings here as numbered rows (`D…`). Specs and PRs may cite a row id (for example D95) instead of repeating the full ruling.

This file is public. Do not put secrets, credentials, tokens, internal addresses, personal information, or quota details here. Keep machine-local Claude plan copies (`~/.claude/plans/cairn-plan.md`) aligned with this file when both exist; this path is the source of truth.

Ticket-scoped design and implementation plans stay under `docs/plans/`. Runtime step handoff plans stay under `$CAIRN_HOME/plans/` and must not be committed from a checkout.
