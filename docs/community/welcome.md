# Welcome to Cairn Discussions

Cairn runs an agent on your own machine and delivers gated pull requests: the agent works, the gates run, and you decide whether the change lands. This is where people who run it help each other.

## Where to post

| Category | Use it for |
|---|---|
| **Q&A** | Installing, configuring and using Cairn. Ask here first; answers stay searchable for the next person. |
| **Show and tell** | What you built, what your first gated pull request changed, and what you learned while it ran. |
| **Ideas** | A change you want to see, before it becomes an issue. |
| **General** | Everything else about running Cairn on your own hardware. |

## Where not to post

- **Bugs and confirmed feature work** belong in the [issue tracker](https://github.com/xiechimon/cairn/issues), where a maintainer labels them before an agent picks them up.
- **Security reports** never go here. Follow [SECURITY.md](../../SECURITY.md) and report privately.

## Before you ask

1. Read the README section for the install path you used.
2. Search existing discussions; someone may have hit the same setup step.
3. Redact secrets. API keys, tokens, `.env` contents and private repository names do not belong in a post, a log paste or a screenshot.

## Your first gated pull request

If Cairn is the reason a pull request merged, the **Show and tell** category is a useful place to say what it changed and how long the first one took. Nothing is posted on your behalf: if Cairn offered you a prefilled post, you choose whether to submit it, and [docs/privacy.md](../privacy.md) lists exactly what the prefilled text contains.

## Conduct

Technical disagreement is welcome. Personal attacks, spam and disclosed secrets are removed.
