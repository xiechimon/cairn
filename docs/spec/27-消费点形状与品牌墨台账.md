# 27 · 消费点形状与品牌墨台账（#1054 / #1055）

> 正典链：ADR 0012 D1（registry 默认几何为正典，用户自行决定只经 token 层生效）+
> #987（`--primary` 保 neutral，品牌只走 spot 族）+ #1006 R4（链接对齐 `--primary`）。
> 机器台账 = `scripts/ui-consumer-registry.json`（两段：`squareBoxes` /
> `brandInkText`），闸 = `scripts/ui-consumer-shape-gate.mjs`（形状）+
> `scripts/ui-drift-gate.mjs` G6（品牌墨角色）。本册是人读面：口径、逐处处置、

## 0. 为什么有这本台账

ADR 0010 那一轮的授权是「几何自由重设计」，全 App 消费点照方正画；ADR 0012
把正典翻成「registry 默认几何为正典」，但迁移面只覆盖了 `components/ui`
（#1003 + #989 闸）。结果：件是圆的，画件的地方还是方的——协调者 2026-10-08
侦察数出 73 处「看得见的方形盒」（32 文件）。同期 #987/#1006 R4 把品牌墨
`--card-button` 限定为 spot 强调（选中标记 / 指示 / 小徽标 / 实底），侦察数出
25 处把它当文字色用（17 文件）——用户看到的就是「有的紫、有的黑」。

两类缺陷共同的根因是**闸的盲区**：#989 registry 闸只看 `components/ui`
同源性；`ui-debt-gate` 数 CSS 行数与裸控件；`ui-drift-gate` G1–G5 查 hex
逃逸与死选择器——没有一个判「消费点画盒的形状」或「正典槽用错角色」。
波 1 六车道（#1004–#1010，PR #1057–#1075）按域清了大半；本台账收口剩余
部分并把两类判据下沉成机器闸。

## 1. 口径（什么算「画盒的消费点」，什么算「正当中和」）

扫描面 = `apps/web/src/**/*.{ts,tsx}` 去掉 `components/ui/`（那里是 #989 的
面，其 `rounded-none` 多是中和原语形状，属正当）。注释先剥（与 registry 闸
共用 `scripts/ui-normalize.mjs` 的单一实现），逐行判：

**R1 · 主动方角声明**：行内有**裸** `rounded-none` 工具类（无变体前缀；
`before:rounded-none` 属状态层形态，不是元素盒），且同行有**无条件涂装**：

- 裸 `bg-*`（除 `bg-transparent` / `bg-none` / `bg-clip-*`）；
- **结构border**：裸 `border` 或宽度形 `border-2` / `border-[1px]`。
  颜色形（`border-(--x)`、`border-input`、`border-primary`）、单边形
  （`border-t/-b/-l/-r/-x/-y` 及带值变体如 `border-l-4`）、样式形
  （`border-dashed`，无宽度不显形）、reset（`border-none/transparent`）
  都**不算**结构 border；
- `shadow-*`（除 `shadow-none`）或 `[box-shadow:…]`；
- `ring`（除 `ring-0` / `ring-inset` / `ring-offset*`）。

**R2 · 沉默的围合盒**：行内**没有任何**裸 `rounded-*` 声明，却同时有结构
border 与裸 bg 填充——方角来自沉默（Tailwind 缺省 border-radius = 0）。

**正当中和（不判为盒）**：

- 状态变体涂装（`hover:` / `data-*:` / `aria-*:` / `before:` 前缀的 tint）
  ——平面行的 hover/选中淡漆不是静息盒；其几何归属所在行族（如 sidebar
  `before:` pill，L1 #1058 裁决 2：「it is the tint, not the button box」）。
- `border-none bg-transparent shadow-none` 形的原语中和串（ghost 行钮、
  弹层壳wrapper、盒内零装饰 input）。
- 全出血带（dialog 头/脚 `border-t` 带底、`border-l-4` 引文块）：单边
  border 不围合，是骑在父盒上的版面带。

**已登记盲区**（诚实声明，闸 v1 不判）：

1. **bg-only 无框无投影无圆角声明**的版面条（如 `bg-(--secondary) px-4`
   的分区条）不命中 R2——把 42+ 行版面背景全部拉进台账的噪声大于收益。
   本次清点人工走查过这一族：chief-settings 卡族（CARD_CLS 等）按家族
   单位一并处置（§2），其余属分区版面，不是「盒」。
2. **非方角的几何偏离**（如 `rounded-full` 药丸、8px 一次性档）不在本闸
   射程——判「任意几何是否接得上 registry 依据」需要逐盒指认件，无法逐行
   机械判。既有登记实践 = 实审裁决 + 调用点注释（filter-chip 药丸，
   L1 #1004 裁决 4；org-chart 节点 8px，L2 #1005）。闸 v1 的强制面 =
   #1054 验收点名的方角缺陷族（「拿不到 registry 依据的一处方角必须红」）；
   把非方角偏离也拉进台账 = 全量盒台账工程（每个药丸/圆盘/一次性档一条），
   留给后续票按同一 ledger 形态扩，不在本票扩权。
3. **跨常量组合的类串**（base 常量 + 变体常量拼接）按行扫描看不全：
   组合后的有效几何**不由闸强制**（行级扫描看不到组合态）；台账的
   rides-primitive / state-surface 条目是对闸命出行的文档化处置，
   组合面靠评审与本册人工走查兜底。

**品牌墨文字角色口径（G6）**：消费点里 `text-(--card-button)` /
`text-(--focus-ring)` / `text-[var(--card-button)]` / `fill-`/`stroke-` 同形 /
任意属性形 `[color:var(--card-button)]` / CSS `color: var(--card-button)`
= 文字角色用品牌墨。每一处必须在台账
`brandInkText` 段登记 `{file, anchor, role, reason, contrast}`，role 限
`selection-mark`（选中标记）/ `indicator`（指示）/ `badge-glyph`（小徽标
字形）——即 #987 的 spot 角色。实底（`bg-(--card-button)`）是该槽正典
角色（卡片按钮实底），不查。正文/标签/行值 → 文本三阶；主操作按钮 →
`--primary`（registry Button default 档）；链接 → registry link 档
（`text-primary` + hover 下划线，#1006 R4）。对比度按 #988 方法实测
（WCAG 2.1 `(Lhi+0.05)/(Llo+0.05)`，双模，不许估）。

复扫命令（口径的机械定义以此为准，闸脚本是唯一实现）：

```sh
node scripts/ui-consumer-shape-gate.mjs   # R1/R2 + 台账双向对账
node scripts/ui-drift-gate.mjs            # G1–G6（G6 = 品牌墨角色）
```
