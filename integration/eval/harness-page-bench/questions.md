# Question bank

Ten page-generation tasks. Each harness receives the same prompt text and produces a single runnable page (HTML + CSS + JS, or a small app). Each question is run 3 to 5 times per harness.

## Q1 Landing page

Marketing landing page for a fictional productivity tool. Hero, feature grid (3 features), pricing table (3 tiers), footer. Responsive down to 360px.

## Q2 Dashboard

Analytics dashboard with a sidebar, top metric cards (4), one line chart, one bar chart, and a recent-activity table. Dark and light theme toggle.

## Q3 Form

Multi-step registration form (3 steps) with client-side validation, progress indicator, and a review/submit step. Error states visible.

## Q4 Interactive tool

A small interactive calculator (mortgage or unit converter) with live results, input validation, and a reset button.

## Q5 Data table

Sortable, filterable data table with 50 rows, pagination, row selection, and an empty state.

## Q6 Modal flow

A page with a modal dialog containing a form; focus trap, Escape to close, and backdrop click to close.

## Q7 Responsive gallery

Image gallery with grid layout, lightbox on click, and keyboard navigation.

## Q8 Empty and error states

A list view that demonstrates loading, empty, and error states with retry.

## Q9 Accessibility

A page that must pass axe-core with no violations: semantic landmarks, labels, keyboard operability.

## Q10 Performance budget

A landing page under 100KB total (HTML+CSS+JS) with no external requests, Lighthouse performance >= 90.

## Common requirements

- No external network requests at runtime.
- Must build or open directly in a browser.
- Console must have no errors.
