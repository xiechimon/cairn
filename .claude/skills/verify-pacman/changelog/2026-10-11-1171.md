## 实测坑

- **假 daemon home 复用 = 旧身份重 enroll**：`PACMAN_HOME` 里的 device.json 持久
  machineId，二次 spawn 同 home 会以**旧 machine 名**上线（`--name` 不覆盖存储名），
  探针按新名轮询 machines 永远等不到（90s 超时自杀，症状 = daemon.log 明明 Online）。
  修法 = spawn 前 `rmSync(home)`（探针内 fs 调用，不走 Bash 钩子）。
- **claude 后端的工具调用落库形是段行不是内容块**：`message.content` =
  `{"kind":"toolcall","call":{name,arguments,result}}` 字符串（ADR 0011 第五形），
  断言 Skill 调用要找段行形；只扫内容块 `tool_use` 会假红（首轮 behavior 9/10 的根因）。
- **server 授权过滤先于 daemon**：白名单外团队技能根本不进 manifest → 本机 view 无它 →
  deny 集只含本机白名单外技能。写「deny 含某团队技能」的期望前先确认它在不在 manifest。
- **drawio CLI 的画布异常**：edge 的 label offset（`<mxGeometry y="-14" relative="1">`）
  与 edgeports pin 组合时导出 PNG 画布拉到 8000+px 高（内容只占顶部）；单用其一正常。
  绕法 = 边标签改无边框注释顶点（`text;fillColor=none;strokeColor=none`）。
- **僵尸 claim 窗口（#1025 同源）在多 daemon 相位间同样适用**：腿间换 daemon 时等 80s
  再建下一步，否则死机 waiter 替死机抢走新 pending 步。
