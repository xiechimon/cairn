## 实测坑（新增）

- **launch.mjs 的 portFree 在 macOS 上会假阳**：fetch 探 8801 得 timeout
  （非 ECONNREFUSED）判「被占」，而 `nc -z`/`net.createConnection` 证明端
  口没人听——别死磕原端口，按 brief「撞了顺延并报告」换口（本票
  8801→8802）。
- **定制 probe 的 jfetch 语义与 drive-1025 不同**：1025 的 jfetch 第三参是
  `{ body }` 包一层；自写探针时直接传裸 body——包错层 server 报
  `providerId expected string, received undefined`，且报错点在 provider
  create（最早的 POST），一眼看不出是包装问题。
- **probe 脚本过一次 biome --write 后缩进会变**：python 整块 replace 的
  old 串必须按当时文件缩进取，否则静默不中（无 assert 时零反馈）——改前
  grep -n 现场取形。
- **stub 恒回 toolcall = 无限工具环**：pi 每轮把工具结果送回、stub 再发
  toolcall……daemon.log 一秒数行 usage（实测 497 行仍未停）。stub 必须轮次
  交替：首个真应答给写 plan.md 的 toolcall，其后一律纯文本收轮（drive-1025
  的 responses 数组同律，自写单 server 时忘了带）。
