探针在 live 栈上造两张 review 卡：空 `changesDiff` 与一文件 diff。执行 Agent 只有「推送分支」。打开看板「完成」弹层，截图并断言合并行是否出现、完成钮是否可点。after 模式再点完成，核对相位 done、零 merge 步、时间线「标记为已完成」。

- 当前 main 创建 Agent 必带 `machineId`。探针先建 api-key、enroll，再把 enroll 返回的 machineId 传给创建。provider 重跑会 409，探针接受 201 或 409。

- server 是 tsx 不带 watch。`readBuildChanges` 的 `reported` 改完必须 cleanup 再 launch，DB 会被清掉。
