# 2026-10-10 — #1166 drive.mjs api-key/search 探针迁语义载体

## skill

`scripts/drive.mjs` 的 api-key 与 search 两条探针路径迁到 spec 22 §5 语义载体
(#950/#910 类名退役后的欠账,票 #1166):

- **api-key**:空态 `.keys-empty` → `getByTestId('keys-empty')`;新建钮 →
  空态 scope 的 `getByRole('button', { name: '新建密钥' })`;弹窗
  `.apikey-form-create` → `getByRole('dialog', { name: '新建密钥' })` scope 内
  `getByRole('button', { name: '创建' })`;一次性明文 `.keys-once-value` →
  `<code>` 语义元素(hasText `pacman_`);掩码行 `.keys-row` →
  `[data-slot="card"]` 过滤「文本含 pacman_ 且无 code 子孙」。
- **search**:面板 `.search-panel` → `getByRole('dialog', { name: '搜索' })`;
  输入 `.search-input-row input` → 面板 scope 的 `getByRole('textbox')`;
  结果行 `.search-row--todo` → 面板 scope `[data-row-kind="todo"]`
  (与 e2e `search-focus.spec.ts` 同律)。
