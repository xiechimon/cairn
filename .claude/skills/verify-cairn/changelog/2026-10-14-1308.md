## Measured pitfalls

- Agent creation must carry `machineId` (#1259). The seed order is provider ->
  api-key -> enroll -> create agent with machineId.
- The server is run directly by launch.mjs under tsx, no watch. After shared /
  server changes you must cleanup and relaunch, otherwise the probe still hits
  the old process.
