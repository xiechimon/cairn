# 2026-10-14 — #1279 the restart combo row pops as a user bubble after title drift

New custom probe `scripts/drive-1279-restart-combo.mts` (pure live stack +
fake-machine transcript upload, zero daemon zero LLM). Five user wire rows are
seeded into the same session: the feedback original text, the bare task text
after drift, the bare restart instruction, the combo row with the current
title, the combo row with the old title. `--expect=old` reproduces before the
fix (the drifted combo row becomes a bubble, the other four rows' classification
unchanged); `--expect=new` after the fix asserts that row exits. Evidence
`docs/verify/1279/`, before 6/6, after 6/6.

## Measured pitfalls

- Agent creation must carry `machineId` (#1259): the seed order is provider ->
  api-key -> enroll -> open runtime -> create agent with machineId. Missing
  machineId 400s outright.
- The probe is `.mts`, run from `apps/server` with `pnpm exec tsx`.
  `@pacman/shared` is imported by repo-relative path; Playwright uses the repo
  root `package.json`'s `createRequire`.
