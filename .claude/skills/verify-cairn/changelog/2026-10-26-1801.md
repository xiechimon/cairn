# 2026-10-26 · #1801 archive stale per-ticket drive scripts

Stale probes named `drive-<number>` moved out of `.claude/skills/verify-cairn/scripts/` into `docs/verify/<ticket>/<script>`, next to their evidence. Current and host-bound ticket probes stay in `scripts/`. Feature-named `drive-*.mjs` scripts and the shared helpers stay too.

`vp-registry.json` points each moved case at the archived path, so `vp.mjs drive <feature> <case> --force` still runs it. The registry gate allows a ticket-named script outside `scripts/` only when the file name is one of those archived probes and the path is exactly `docs/verify/<ticket>/<script>`. A new `drive-<number>` script, the same file put back under `scripts/`, or the same file under the wrong ticket directory, still fails the gate.

Historical changelog entries and evidence READMEs still name the old `scripts/drive-<number>.mjs` paths. Those records were not rewritten.
