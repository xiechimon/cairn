# GitHub emulator evidence (#3137)

Added the github-emulator/pr-watch drive case and recipe. It runs emulate@0.13.0 through npx with scripts disabled, records real loopback requests/responses and SQLite transitions, and captures a real Swagger UI request/response plus official docs. The server GitHub API helpers accept CAIRN_GITHUB_API_BASE_URL while retaining production defaults. OAuth, daemon calls, E2B and Langfuse remain outside this example.
