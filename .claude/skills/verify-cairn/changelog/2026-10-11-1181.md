# 2026-10-11 — #1181 drive-hotkeys / drive-newtask-key migrate retired search selectors

#1166 only migrated the two probe paths in `drive.mjs`; the same retired
selectors still live in the two hotkeys-family scripts (ticket #1181) and fail
on every run. This ticket migrates them and, along the way, fixes two earlier-
wave same-root stales in the same scripts (they hid behind the #1181 red dots
and were never reached before the migration):

- **5 search-panel spots** (the ticket's list): `drive-hotkeys.mjs`'s
  `pressUntil(page, 'Meta+k', '.search-panel')` and `.search-input-row input`;
  `drive-newtask-key.mjs`'s panel waitForSelector / input locator / panel
  hidden waits x3. All migrate to the #1166 shape — panel =
  `getByRole('dialog', { name: '搜索' })`, input = the panel-scope
  `getByRole('textbox')`, same rule as the e2e `search-focus.spec.ts`.
- **`.kbd-hint` retirement debt** (the #983/#1004/#1008 wave): the segment-3b
  `button[aria-label="总管"] .kbd-hint` count / data-slot / rest-hidden
  assertions in drive-hotkeys are permanently red after #1008. Migrated to the
  registry Tooltip+Kbd probing method (same rule as drive-1008 E1): trigger =
  `getByRole('button', { name: '总管' })`, shell =
  `[data-slot="tooltip-content"]`, keycap = `[data-slot="kbd"]` inside the
  shell (⌘J). The rest criterion becomes "tooltip not mounted" (count=0).
- **Drawer resident-mounted + Esc does not close the window** (ADR 0013 D3/D6):
  the segment-4/5 `drawerCount === 0` and Escape-close waits are permanently
  red after D6 (the closed aside is hidden-but-mounted). The open criterion
  becomes `isVisible()`; closing becomes the ⌘J toggle (same rule as the e2e
  hotkeys.spec).

`pressUntil` is generalized to accept a CSS string or a Locator (the string form
keeps the original waitForSelector first-match semantics via `.first()`);
`page.inputValue(locator)` is a Page-level API that only takes selector strings —
a Locator's value read must go through the locator's own `.inputValue()` (hit on
the spot during the first green run).

The retirement-audit list (the styleSheets assertions in `drive-949-overlays` /
`drive-947-secondary`) is untouched, kept per the ticket surface.

Feature map: `features/hotkeys.md` synced in three places (the chief-wake
toggle/resident-mounted carrier, the kbd-hint registry carrier, the full-chain
link description).
