## New measured pitfalls

- **`symbolic-ref --short refs/remotes/origin/HEAD` returns `origin/master`**
  (with the origin/ prefix) — concatenating `refs/remotes/origin/<that>` yields
  `origin/origin/master`, an empty read; to judge the remote tip, use
  `rev-parse refs/remotes/origin/HEAD` directly (the symref dereferences
  itself).
- **Two daemons on one stack steal claims from each other**: while both
  machines are online the long-poll is first-come-first-served, for leg B to
  have the stack to itself you must kill A and wait > 75s to pass the zombie-
  claim window (the two-daemon variant of the #1025 gotcha; the script has the
  80s built in).
- **A github-form build step's push surface always fails anonymously**: an
  anonymous repo (octocat/Hello-World) has no write permission — this ticket's
  acceptance surface is the materialization seam (source-selection log +
  base/conv git artifacts), the step's terminal state failed (the stub's
  zero-change artifact gate) does not affect the reading; do not fake
  credentials for the push surface.
