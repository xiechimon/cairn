## 实测坑（新增）

- **`symbolic-ref --short refs/remotes/origin/HEAD` 回 `origin/master`**（带
  origin/ 前缀）——拼 `refs/remotes/origin/<它>` 会得 `origin/origin/master`
  空读；判 remote tip 直接 `rev-parse refs/remotes/origin/HEAD`（symref 自行
  解引用）。
- **双 daemon 同栈会抢认领**：两机都在线时长轮询先到先得，B 腿想独占必须杀
  A 后等 >75s 过僵尸 claim 窗（#1025 gotcha 的双 daemon 变体；脚本内置 80s）。
- **github 形态 build 步的 push 面匿名必败**：匿名仓（octocat/Hello-World）
  无写权——本票验收面在材料化 seam（选源日志 + 基座/conv git 实物），步终态
  failed（stub 零改动产物闸）不影响判读，别为 push 面造假凭证。
