## New measured pitfalls

- **The discrimination shape of "blocked" is a long-poll hang, not an empty
  response**: the claim long-poll holds for 75s by default (the
  `CLAIM_POLL_INTERVAL_MS` constant, no env override), a gate-blocked claim does
  not return `{step:null}` but hangs forever — the probe uses a child-process
  fetch + client-side `AbortSignal.timeout` to judge "hang = no step to give",
  and reuses the same parked claim's return after done+wake as the slot-handoff
  criterion (parked -> takes A2 immediately, one leg serving twice).
- **done's 200 != step done**: a hosted project closing with zero changes is
  beaten to failed by the artifact gate — acceptance assertions write "terminal
  state (done|failed)"; the agent-count slot release and wake both hold for
  either terminal state (wake is at the head of finishStep, before the fork).
