# 2026-10-09 · #1094 总管切换器长列表滚动

新增定制 probe `scripts/drive-1094-threads-scroll.mjs`（双向：`--expect=new`
21 检查 / `--expect=old` 14 检查），证据 `docs/verify/1094/`。feature map 无
新增面——chief 抽屉切换器面的 live 取证入口即本 probe。

铺底手法新增：**长线程列表全走 `POST /chief/threads` 公开 REST 建**（22 条，
零 daemon 零 LLM 零 SQL；标题 = 首句截断，API 回读为准）——比 sqlite 直插
chief_thread 干净（不用猜 chiefId / sessionId 列），比 stub 回合便宜（不建步
不 claim）。`listChiefThreads` 按 updatedAt 降序，尾行 = 最先建的那条，探针
据此钉「点尾行 → 头部 chip 切到尾行标题」。

实测坑新增：

- **`locator.click()` 对 fixed 祖先裁剪不做命中测试**——改前尾行被窗体
  `overflow-hidden` 裁掉，`locator.click()` 照样放行（只查 elementFromPoint
  于元素自身盒内？不——它跳过 fixed clip 检查）。要钉「点不到」必须用
  `page.mouse.click(坐标)` + 后果断言（active 切换），或 `elementFromPoint`
  于尾行中心点（改前 = null，行在视口外）。e2e 面同律：新 spec 的点击带
  `force: true` 并在注释里写明原因，几何判据另走 boundingClientRect。
- **`--available-height` 只由 Base UI Positioner 注入**：全仓仅
  `dropdown-menu.tsx` / `select.tsx` 在 Positioner 内消费它；普通绝对定位
  div 上 `getComputedStyle().getPropertyValue('--available-height')` 恒空
  ——「registry 默认为正典」的封顶形态不能照抄到 Positioner 外的容器，
  探针 N13/O12 把这个实测钉进证据。
- **短列面零变化的最强证据是截图逐字节相同**（`cmp` 两面
  `01-short-list.png`，sha 一致）——几何断言（68px/262px）之外补这一条，
  连抗锯齿差异都排除了。
