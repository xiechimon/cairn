New measured pitfalls:

1. **The verify stack's GitHub egress needs `NODE_USE_ENV_PROXY=1`**: the server's
   direct connection to raw.githubusercontent.com is intermittently reset
   (api.github.com is stable) — symptom = URL import 502 "fetch failed" or the
   dialog hanging long (12 files x 15s timeouts can stack past 120s); launch the
   stack with `NODE_USE_ENV_PROXY=1` (the deployment shape recorded in
   lib/github.ts's header note) to go through the local proxy and it is stable.
   launch.mjs itself does not set it — the probe must put it on the launch command
   line before running.
2. **anthropics/skills' folded frontmatter shape picks targets**: directories like
   `skills/academy-guide` with a `description: >` folded form fall back to default
   under the minimal parser -> import 400 "description is required"
   (parseSkillFrontmatter's existing semantics, not this ticket's defect); choose a
   directory with a single-line description (skills/pdf is one).
3. **Phase B runs the real network** (14 egress requests) — on network flakiness
   just re-run the script, do not misjudge it as an implementation regression
   (phases A/C/D have zero external-network dependency and can be located
   separately).
