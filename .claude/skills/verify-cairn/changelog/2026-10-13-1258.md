## 实测坑（新增）

- **agent 创建必带 machineId（#1259 起）**：探针 seed 序从「provider →
  agent → key → enroll」改为「provider → key → enroll → agent」——
  createAgentBodySchema 的 machineId 是必填 recordId，server 校验该机在
  团队且 runtime 匹配；沿用 702/903 老探针的 seed 序会 400
  `invalid body at machineId`。enroll 响应即 machine.json 形状，id 直接
  可用。
- **done(failed) 的错误文本要避开 quota 桶词面**：
  classifyStepFailure 命中 quota（402 / usage limit / quota / credits /
  rate limit 等）会走 #1257 挂起腿——步不判死、todo 不落 failed，探针
  卡在 phase 断言。堆栈/git 报错风格词面落 other 桶，失败漏斗正常。
- **失败行 title = errorMessage 全文**（多行原样进 DOM，渲染时换行折叠
  视觉成空格）：行级断言别按「首行」写——textContent 与全文逐字节比对
  才是「行 title 承载全文」的正判据。
