One Cairn server can coordinate multiple physical and virtual execution machines at once. While most solo developers start with the Mac desktop app—which automatically enrolls its own local Runner—you can attach extra Linux workstations, home servers, or cloud VPS boxes using `@xiechimon/cairn-cli`, or graduate to the advanced headless Linux server (`npx @xiechimon/cairn` or Docker) when you want a server that never sleeps.

## Choosing your topology

| Setup | Server location | Best for |
|---|---|---|
| **Mac desktop + extra Runners** | Cairn Mac app (over Tailscale or LAN) | Mac-first users who occasionally offload heavy Linux builds to a VPS |
| **Headless Linux server + Mac/VPS Runners (advanced)** | `npx @xiechimon/cairn` or Docker | 24/7 control plane in a homelab or cloud VM with multiple enrolled machines |

## Enrolling an extra Runner

On any machine with Node.js 22.19+ (22 or 24 LTS) and Git:

```sh
npm install -g @xiechimon/cairn-cli@latest
cairn start --server https://<your-server-url>
```

If the remote machine has no browser, generate an API key in **Settings -> API keys** and run:

```sh
cairn start --api-key <cairn_...> --team <teamId> --server https://<your-server-url>
```

## Important project-form boundary

- **GitHub-connected projects** clone from GitHub, so any online Runner with the required runtime can pick up the next task.
- **Local-folder projects** bind to an absolute path on one specific machine; if that Runner goes offline, tasks stay `Queued` until that host reconnects.
