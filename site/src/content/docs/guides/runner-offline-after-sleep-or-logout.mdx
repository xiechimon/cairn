A Cairn Runner goes **Offline** after Mac sleep or SSH logout because macOS suspends background execution when asleep, and on Linux a transient unit or background process spawned by `cairn start` exits when your login session ends. Because enrollment credentials stay saved in `machine.json`, you never have to re-approve the machine—you only need to keep the host awake or use a persistent service.

## On macOS (Mac desktop app)

- **Closing the window is safe; quitting stops the Runner:** Closing the Cairn window hides it while keeping the server and Runner alive in the menu bar. Only choosing **Quit Cairn** stops them.
- **Prevent automatic sleep on a Mac mini:** In macOS **System Settings -> Energy** (or **Battery -> Options** on desktop-mode Macs), enable **Prevent automatic sleeping when the display is off**.
- **Built-in wake support:** When **Keep the Screen On** is enabled or a scheduled run is imminent, the Mac desktop app keeps the display awake and swaps the menu bar icon to show the cup indicator.

## On Linux (standalone CLI Runner)

If a Linux Runner stops when your SSH session disconnects:

```sh
cairn start          # reconnects immediately using ~/.cairn/machine.json
```

To make it survive reboots and logouts permanently, follow [Keep a Linux Runner online with systemd](/guides/keep-linux-runner-online-systemd/) (`cairn start --foreground` inside `~/.config/systemd/user/cairn-daemon.service`).
