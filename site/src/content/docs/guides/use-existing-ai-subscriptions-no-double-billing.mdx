Cairn is completely free (Apache-2.0) and never resells tokens or adds a cloud markup on top of your AI spend. You connect the ChatGPT subscription, Claude Code subscription, or provider API keys you already pay for, and model requests travel straight from your own machine to your chosen provider.

## Supported ways to supply models

| Connection type | How Cairn connects | Extra cost from Cairn |
|---|---|---|
| **ChatGPT / Codex subscription** | Browser device-code login inside Cairn (`pi` executes tasks) | $0 |
| **Claude Code subscription** | `claude setup-token` (`sk-ant-oat01-…`) stored encrypted on your server | $0 |
| **Provider API keys** | OpenAI, Anthropic, Google Gemini, xAI, or compatible relays | $0 (provider usage only) |
| **Local / keyless endpoints** | Custom OpenAI or Anthropic-compatible URL with auth header disabled | $0 |

## Why subscription billing stays separate from API billing

Just as OpenAI separates ChatGPT Plus/Pro web limits from `platform.openai.com` prepaid API credits, Cairn respects whichever connection type you configure under **Settings -> Model**:

- Using **ChatGPT subscription** routes through your ChatGPT plan without requiring an OpenAI API key.
- Using **Claude (Subscription)** routes through your Claude subscription without needing Anthropic API credits, provided `claude` CLI is installed on the Runner.
- Using **Test connection** in provider settings sends one live check request and may incur normal provider API charges when testing an API key.

For full pricing and future Cairn Cloud scope, see [What does Cairn cost?](/guides/what-does-cairn-cost-open-source-license/) and [Connect a model](/docs/models/).
