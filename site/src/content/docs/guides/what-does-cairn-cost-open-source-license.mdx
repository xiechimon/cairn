Cairn is 100% free and open source under the **Apache-2.0** license today, with zero paywalled features or compute markups. You download the Mac desktop app (or run the advanced self-hosted server) at no cost and bring your own ChatGPT, Claude Code, or provider API credentials.

## Today vs planned direction

- **Available today (free, Apache-2.0):** The Mac, Windows, and Linux Electron desktop apps, the `@xiechimon/cairn` server, the `@xiechimon/cairn-cli` Runner, Tailscale remote access, IM adapters, and local/GitHub workflows. Only a tiny rotating holdout subset of the `eval/` benchmark suite stays private so agents cannot overfit to test answers.
- **Planned (not available today):** An official paid hosted option called **Cairn Cloud** is planned for developers who eventually want a managed server and ephemeral cloud VMs without keeping a home machine online. It is **not shipped yet** and has no free cloud tier.

## Will self-hosting ever get gated?

No—Cairn's project positioning explicitly commits to keeping open-source self-hosting and the desktop app free with complete functionality under Apache-2.0, while any future Cairn Cloud billing lives in a separate hosted control plane. If you need a zero-install hosted SaaS today, Cairn is not the right fit yet.
