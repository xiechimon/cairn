As of November 2026, the official [BloopAI/vibe-kanban](https://github.com/BloopAI/vibe-kanban) README explicitly states **"Vibe Kanban is sunsetting."** For developers looking for an actively maintained open-source alternative on macOS and Linux, **Cairn** offers a native desktop app for macOS, Windows and Linux, isolated git worktrees per task, existing subscription support, and an active Apache-2.0 codebase.

## Feature comparison (checked 2026-11-27)

| Capability | Cairn | Vibe Kanban |
|---|---|---|
| **Project status** | Active Apache-2.0 development | Sunsetting ([shutdown notice](https://github.com/BloopAI/vibe-kanban)) |
| **Primary install** | Mac DMG (`arm64` / `x64`), Windows/Linux desktop, or `npx @xiechimon/cairn` | `npx vibe-kanban` |
| **Task workflow** | Coordinator chat + task list (`Ready for review`, `Needs input`, `In progress`, `Resolved`, `To start`) | Kanban board + workspace branch/terminal/dev server |
| **Supported agents** | Built-in pi (ChatGPT, Gemini, relays) + Claude Code + Devin | 10+ CLIs (Claude Code, Codex, Gemini CLI, Amp, Cursor, OpenCode, etc.) |
| **Remote & multi-machine** | Extra Runners (`@xiechimon/cairn-cli`), Tailscale mobile HTTPS, Telegram/Slack/WeChat | Local single-host browser preview + devtools |

## Where Vibe Kanban is better

Vibe Kanban supported a wider array of third-party CLI harnesses out of the box (over ten agents including Amp, Cursor, OpenCode, and Qwen Code) and bundled an in-UI app preview with device emulation and inline diff comments for web frontend iteration.

## Migrating your workflow to Cairn

1. Download the [Cairn desktop app](/guides/install-cairn-mac-desktop-app/) (or run the headless server with `npx @xiechimon/cairn`).
2. Connect your ChatGPT subscription (no Codex CLI install needed) or `claude setup-token` under **Settings -> Model** ([Models guide](/docs/models/)).
3. Point Cairn at your existing local Git folder or GitHub repo; each task still isolates in its own worktree and lands only after your merge approval.
