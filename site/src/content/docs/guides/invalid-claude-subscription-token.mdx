Cairn rejects a Claude subscription credential when the pasted string is not an `sk-ant-oat01-…` subscription setup token, has been revoked or expired, or was confused with a standard Anthropic API key (`sk-ant-api…`). Mint a fresh token with `claude setup-token` and verify it directly in **Settings -> Model**.

## Check which credential type you actually have

| Credential prefix | Where it goes in Cairn | Requires `claude` CLI? |
|---|---|---|
| `sk-ant-oat01-…` (from `claude setup-token`) | **Settings -> Model -> Add provider -> Claude (Subscription)** | Yes, on Runners running Claude Code |
| `sk-ant-api…` (from Anthropic Console) | **Settings -> Model -> Add provider -> Anthropic (API key)** | No (runs via bundled pi) |

## Regenerate and re-verify a subscription token

1. On a machine signed in to your active Claude subscription, run:
   ```sh
   claude setup-token
   ```
2. Copy the complete `sk-ant-oat01-…` line with no trailing whitespace or quotes.
3. Under **Settings -> Model**, replace the connection token and click **Verify**.
4. Cairn calls the Anthropic account API to confirm the token is active; if it reports an authentication failure, run `claude auth login` first to refresh your local Claude sign-in, then re-run `claude setup-token`.

Note that running `claude` interactively in Terminal (or `cairn claude login`) alone does not replace the team subscription token inside Cairn ([Models guide](/docs/models/)).
