ChatGPT Plus and Pro subscribers can run autonomous coding tasks in Cairn without installing the Codex CLI or running `codex login` on every machine. The Cairn Mac desktop app bundles the **pi** execution engine directly inside its local Runner, so completing the in-app device-code authorization connects your existing OpenAI subscription end to end.

## What happens on a fresh ChatGPT-only setup

When you open the Mac desktop app for the first time, the onboarding wizard walks through two screens:

1. **Connect models:** Choose **ChatGPT subscription**, open the displayed device-login URL in your browser, sign in to your OpenAI account, and enter the code while keeping Cairn open.
2. **Confirm settings:** On a fresh setup with only ChatGPT connected, **Coordinator** selects **GPT-6.1 Sol** and dispatches tasks through bundled **pi** (unless existing routing rules override it). Click **Confirm and start chatting**.

## Mixing subscriptions, API keys, and custom endpoints

You are not locked into one model source. Under **Settings -> Model**, you can combine:

- **ChatGPT subscription** via device login (no Codex CLI required).
- **Provider API keys** for OpenAI, Anthropic, or Google Gemini.
- **Custom endpoints** speaking OpenAI Completions, OpenAI Responses, or Anthropic Messages—useful for local relays or self-hosted gateways, including keyless local endpoints with the authorization header disabled.

Saved routing rules under **Settings -> Model** control which model runs the Coordinator versus background tasks.
