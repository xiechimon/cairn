Cairn treats chat apps as optional outbound entry points into your Coordinator—never requiring public webhooks, port forwarding, or third-party cloud relays. Under **Settings -> Chat apps**, you can connect **Telegram**, **Slack** (DM-only Socket Mode), or **WeChat (iLink)** to receive notifications and answer decision cards from your phone.

## Comparing the supported chat adapters

| Platform | Credentials needed | Transport | Reply format |
|---|---|---|---|
| **Telegram** | Bot token from BotFather | Outbound long polling | Inline buttons + numbered text fallback |
| **Slack** | App token (`xapp-`, `connections:write`) + Bot token (`xoxb-`) | Outbound WebSocket (Socket Mode, DMs only) | Block Kit buttons + text replies |
| **WeChat (iLink)** | QR scan in WeChat (no developer registration) | Outbound long polling | Text & numbered replies (~1,800-char chunks) |

## Setup and pairing safety

1. Open **Settings -> Chat apps** in Cairn and pick your adapter.
2. Enter the token (or scan the WeChat QR code). Tokens are stored encrypted via `secretbox.key`.
3. Send a test message to your bot. Unpaired senders are never trusted automatically; approve your own sender ID inside Cairn settings.
4. Keep secret input inside Cairn settings rather than typing passwords or API keys into chat messages, so third-party chat servers never store your credentials.

For full mobile diff viewing and browser-based Web Push, pair IM alerts with [Tailscale Serve mobile access](/guides/setup-tailscale-mobile-access/).
