Yes—Cairn works completely offline from GitHub when you bind a project to a **Local folder** (`localPath`) on your Mac or Runner. You do not need a GitHub account, OAuth app, or pull request workflow to run tasks, isolate worktrees, or merge finished branches locally.

## How local-folder projects behave vs GitHub projects

When you click **New project -> Select repo** in Cairn, you pick between two repository modes:

- **Local folder:** Point Cairn at an absolute path to an initialized `.git` directory on the Runner's filesystem (for example `~/my-app`). No code leaves that machine for Git hosting, and finished tasks land directly on local branches you can merge locally.
- **GitHub repo:** Connect GitHub or specify `owner/repo`. Progress is pushed to GitHub branches/PRs so any online Runner can pick up subsequent tasks.

## Constraints of the local-folder mode

1. **Must be an initialized Git repository:** Cairn checks that the path is absolute, exists, and is a valid Git repository with at least one commit before creating worktrees.
2. **Bound to one Runner:** Because the source of truth lives on that machine's disk, tasks for a local-folder project stay `Queued` if that specific Runner is offline rather than failing over to another host.
