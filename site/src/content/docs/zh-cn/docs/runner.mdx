Runner 就是装在要让 agent 干活的机器上的 `cairn` 守护进程。它从你的服务端领活，每个 thread 直接在这台主机上自己的 git worktree 里跑，代码和凭证都留在这台机器上。Runner 可以就是服务端所在的那台机器，以后再加别的。

桌面应用已经启动并批准内置 pi Runner，不用再为它安装第二份 CLI。下面的命令用于 npm 或其他机器。Runner 自带 pi，不依赖 Codex CLI 登录；请[在 Cairn 内连接模型](/zh-cn/docs/models/)。在 **设置 → 执行机** 确认这台执行机显示在线。

<Aside type="tip">
优先用一台常开的机器：台式机、家里的服务器或 VPS。笔记本会休眠、断网，活就得等它回来。
</Aside>

## 用浏览器授权注册

这是默认方式，也是网页里 `添加 Runner` 对话框给出的步骤。

<Steps>

1. 在要干活的机器上安装 CLI：

   ```sh
   npm install -g @xiechimon/cairn-cli@latest
   ```

2. 启动它：

   ```sh
   cairn start
   ```

   它会打印一个链接：`Open <url> and approve this machine (expires in 10 minutes).`。如果服务端不在这台机器的 `http://127.0.0.1:8787`，加上 `--server <url>`。

3. 在已经登录 Cairn 的浏览器里打开这个链接，在 `授权 Runner` 页点 `确认授权`。

4. 网页里这台 Runner 显示在线。之后它在后台常驻，不用开着终端。凭证存在 `~/.cairn/machine.json`，以后再启动不用重新批准。

</Steps>

## 用 API key 注册

在手边没有浏览器的云服务器上，展开同一个对话框里的 `在云服务器上运行？改用 API key 注册`，到 `API 密钥` 里创建一个 key（明文只显示一次），然后执行：

```sh
cairn start --api-key <cairn_...> --team <teamId>
```

对话框会帮你填好团队 ID。

## 日常命令

```sh
cairn start          # 在后台启动
cairn stop
cairn restart
cairn status         # 本机和守护进程的状态
cairn logs -f        # 跟踪 daemon.log
```

## 在 Linux 上保持常驻

任务直接在这台执行机主机的独立 git worktree 里运行，不需要容器运行时或 bubblewrap 沙箱。在 Linux 上，`cairn start` 和 `cairn restart` 会优先以随会话存在的 systemd 用户单元 `cairn-daemon-<id>.service` 启动并打印单元名；如果 `systemd-run --user` 不可用，会打印警告并退回普通后台进程，同样可以正常领取和运行任务。

随会话存在的单元或普通后台进程在你注销或重启后会停止。要让 Runner 跨注销和重启一直运行：先按上面注册一次，用 `cairn stop` 停掉，再建 `~/.config/systemd/user/cairn-daemon.service`。两个路径用 `command -v cairn` 和 `command -v node` 查：

```ini title="~/.config/systemd/user/cairn-daemon.service"
[Unit]
Description=Cairn daemon

[Service]
Environment=PATH=/directory/of/node:/usr/local/bin:/usr/bin:/bin
ExecStart=/path/to/cairn start --foreground
Restart=on-failure

[Install]
WantedBy=default.target
```

```sh
systemctl --user daemon-reload
systemctl --user enable --now cairn-daemon.service
```

## 服务端和 Runner 在同一台机器上

两个包都会装一个 `cairn` 命令。同一台机器上两个都全局安装的话，后装的那个占用这个名字。干净的分法是：服务端用 `npx @xiechimon/cairn`，Runner 用全局安装的 `@xiechimon/cairn-cli`。

## Runner 在另一台机器上

服务端只监听本机回环。服务端在一台常开主机上、Runner 在另一台机器上时：启动服务端时把 `HOST` 设成那台主机的局域网地址，同时设置 `CAIRN_TOKEN`（没有令牌时它拒绝绑定非回环地址），再用 `--server http://<主机>:8787` 启动 Runner。见 [configuration.md](https://github.com/xiechimon/cairn/blob/main/docs/configuration.md)。
