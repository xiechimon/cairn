Cairn 是跑在你自己的机器上的开源 agent harness：macOS、Windows x64 和 Linux x64 都有桌面应用，也可以把服务端自托管到别的机器上。你在一个对话里跟 Coordinator 说要做什么；它给每件事开一个 thread，thread 在你自己的机器上、用你自己的模型订阅干活，只在需要你拍板的时候回来找你。用得越久，它越会干你的活。

- **记住你纠正过的事。** 值得留下的纠正会变成记忆，之后相关的时候会被带回来；失败那一轮的教训会写进下一次重试。
- **同一个错再犯，就加一道检查。** 同一个错第二次出现时，agent 会指回那条规则，提议建一个仓库检查任务；你不点头，它不会自己装。
- **它的改动是有评测的。** 评测的题目和评分代码是受保护路径，运行时从合并基点读取，agent 改不了自己要被考的那张卷子。要让改动在这套评测上赢过现在的 harness 才留下，这一步正在做。
- **撤不回的事，都等你点头。** 合并、发送、删除和改凭据，都不会自己动。

Cairn 只给一个人用：你跑你自己的一份，别人想用就跑他自己的。

## 三个组成部分

| 部分 | 是什么 | 跑在哪 |
|---|---|---|
| **服务端** | 你在浏览器里打开的网页应用、Coordinator 和数据库。每人一份。 | 你平时用浏览器的机器，或者一台常开的主机。数据在 `~/.cairn`。 |
| **Runner** | `cairn` 守护进程，领活、跑 thread，每个 thread 在自己的 git worktree 里。 | 每台要让 agent 干活的机器。服务端所在的机器也可以同时当 Runner。 |
| **模型来源** | 你自己的订阅或 API key：Claude Code、ChatGPT / Codex，或服务商的 API key。 | 在 Cairn 内用设备码登录 ChatGPT 订阅，或在 **设置 → 模型** 添加订阅令牌或 API key。ChatGPT / Codex 任务用内置 pi，Cairn 目前不转售算力。 |

三样都齐了，Coordinator 才能回你的话。下面几页按顺序带你走一遍。

## 还在规划、没有上线的

- **得分更高才留下。** 提示词、技能、路由和工具用法上的改动，要在这套受保护的评测上赢过现在的 harness，并守住交付和打扰次数，才会被保留。它依赖的记忆、检查提议和重试教训今天已经在用。方案：`docs/design/harness-self-improve.md`。
- **你自己的事。** 邮件、日程、求职作为一个没有仓库的项目：agent 读、整理、起草，发送和提交等你。现在还不能用。
- **真实作品录屏。** 从提需求到合并的完整录屏，配 PR 链接和查得到出处的数字。

## 不适合你，如果你想要

- 给团队共用的工具，有共享频道、角色和账单（看看 [Amp Spaces](https://ampcode.com/docs/spaces) 或 [Multica](https://github.com/multica-ai/multica)）；
- 只是更好用的界面，自己驱动 Claude Code 或 Codex（看看 [T3 Code](https://github.com/pingdotgg/t3code)）；
- 住在聊天软件里的助理（看看 [OpenClaw](https://github.com/openclaw/openclaw) 或 [Hermes Agent](https://github.com/NousResearch/hermes-agent)）；
- 现在就能用、不用安装也不用维护的托管服务。
