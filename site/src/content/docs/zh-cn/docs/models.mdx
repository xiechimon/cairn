---
title: 接入模型
description: 在 Cairn 内登录 Codex，或使用你自己的订阅令牌、API key。
---

Cairn 内置 pi 执行引擎，不提供模型订阅。请使用你自己的账户或 API key。全新安装会打开 **接入模型（Connect models）**；以后在 **设置 → 模型**（**服务商** 区域）管理连接。

## ChatGPT / Codex 订阅：不用另外装 CLI

1. 在接入模型里选 **ChatGPT 订阅**，或在 **设置 → 模型** 点 **添加服务商**。
2. 在浏览器打开 Cairn 显示的设备登录链接，登录你自己的 OpenAI 账户，输入页面给出的设备码。保持 Cairn 打开，等授权完成；设备码过期就重新开始登录。
3. 回到 **确认设置（Confirm settings）**。全新安装且只连接 ChatGPT 订阅时，**Coordinator** 选择 **GPT-6.1 Sol**（任务默认复用 Coordinator 的模型，并通过内置 **pi** 引擎执行，不是外部 Codex 进程）。
4. 核对模型选择后，点 **确认并开始对话**。

不用安装 pi、Codex CLI，也不用执行 `codex login`。Runner 上 Codex CLI 自己的登录不是这条连接路线的设置步骤。

## 服务商 API key 或自定义端点

在接入模型或 **设置 → 模型** 里选服务商，输入自己的 API key。中转或自建服务选 **自定义端点**，填名称、服务商 ID、Base URL、API 协议和模型 ID。支持 OpenAI Completions、OpenAI Responses、Anthropic Messages 等协议。无密钥端点可以留空 key，并关闭授权请求头。

密钥加密保存在你的服务端。用 **测试连接** 检查是否能调用；这会发起模型请求，可能产生服务商费用。确认前看实际的 Coordinator 模型，不要把 ChatGPT 订阅的默认值套到其他服务商上。

## 可选：Claude Code 订阅

Claude Code 是独立运行时。每台要执行它的 Runner 都要安装 `claude`，Runner 会从 PATH 或常见安装目录检测。Cairn 的任务需要接入团队的订阅令牌；只在本机运行 `claude` 登录不能替代这个令牌。

1. 在一台已登录 Claude 订阅的机器上运行 `claude setup-token`。
2. 到 **设置 → 模型** 点 **添加服务商**，添加标为 **订阅** 的 **Claude**，给连接起名并粘贴令牌；知道过期日期的话一并填写。
3. 点 **验证**，服务端会直接调用 Anthropic 账号接口核验令牌。
4. 在确认设置里核对 Coordinator，或在 **设置 → 模型** 调整 Coordinator 和任务模型规则。可用的 Claude Code 运行时加订阅，会在没有已保存规则覆盖时提供 `claude-sonnet-5-5` 作为任务默认值；Coordinator 有自己的选择。

Anthropic API key 是另一种连接，可通过 pi 使用，不需要 Claude Code CLI。

## 可选：Devin 订阅

只有想使用 Devin 时，才在 **设置 → 模型** 接入并启用 Devin 订阅。服务端确认有启用且未过期的订阅后，Runner 才下载其托管运行时；仅使用 pi 时不下载 Devin。下载完成后，可能还要等一轮状态上报（通常 30 秒）才显示可用。禁用订阅会阻止新的安装尝试，但不会卸载已有运行时或取消正在进行的下载。

## 默认模型与已保存规则

不存在脱离连接情况的统一默认值。全新且只连接 ChatGPT 订阅时，确认页 Coordinator 为 GPT-6.1 Sol，任务默认复用它。其他连接会改变默认选择：任务优先用可用的 Claude Code 订阅和运行时；Coordinator 优先 Anthropic API 连接，再选符合条件的服务商，最后才是可用的 Claude Code。已保存的 Coordinator、任务规则优先。在 **设置 → 模型** 查看或修改。

要完成[第一个任务](/zh-cn/docs/first-task/)，除了模型，还需要一台在线的 Runner。

## 凭证放在哪

在 Cairn 内建立的连接加密保存在服务端数据里。npm 默认在 `~/.cairn/server`；桌面端在应用数据目录：macOS 是 `~/Library/Application Support/@cairn/desktop`，Linux 是 `$XDG_CONFIG_HOME/@cairn/desktop`，默认 `~/.config/@cairn/desktop`。请备份整个数据目录，包括 `secretbox.key`，不要只拷数据库。外部 CLI 的登录与 Cairn 的连接分开。
