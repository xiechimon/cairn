推荐直接使用 Cairn 桌面应用：它内置了网页应用、Coordinator、SQLite 数据库和本地 pi 执行机，并自动完成 owner 登录；macOS、Windows x64 和 Linux x64 都有安装包。只有在需要独立常驻 Linux 服务端或挂载多台服务器时，才需要走下面的 `npx @xiechimon/cairn` 或 Docker 进阶自托管路线。

## 桌面应用（macOS、Windows、Linux）

macOS 从[最新发布](https://github.com/xiechimon/cairn/releases/latest)下载 DMG：Apple 芯片用 arm64，Intel 用 x64。拖进“应用程序”再打开。应用还没有公证；被拦时到“系统设置 → 隐私与安全性”点“仍要打开”（macOS 14 及更早：右键应用选“打开”）。它会启动服务端和 pi Runner，并以 owner 身份登录。不需要 Node.js、单独安装 pi 或 Codex CLI。接着看[接入模型](/zh-cn/docs/models/)。

**Windows x64**：从同一个发布页下载 `-win-x64.exe` 安装包或 ZIP 并运行。它自带服务端和 Runner、自动登录本机，并原地自动更新。

**Linux x64**：从同一个发布页下载 `-linux-x64.tar.gz` 便携归档并解压，或按[桌面构建和解压步骤](https://github.com/xiechimon/cairn/blob/main/apps/desktop/README.md#linux-x64-archive)从源码构建。Linux 没有自动更新。需要图形会话和 Git。应用自带服务端和 Runner，退出会停止两者。无图形界面的 Linux 服务端用下面的 npm 路线。

## 进阶：独立服务端运行环境

- **Node.js 22.19+（22 或 24 LTS）和 Git。** 这两条 LTS 线有预编译的 `better-sqlite3`；别的版本可能要从源码编译，得装编译工具链。
- 服务端跑在 Linux 或 macOS 上。Windows 要多走下面的配对一步。

## 进阶：启动独立服务端

<Steps>

1. 一行命令跑起来：

   ```sh
   npx @xiechimon/cairn
   ```

   它会下载 Cairn 并只在本机回环地址上服务。它不会打印网址，地址就是下面这个。第一次启动会在 `~/.cairn` 下建数据库、跑迁移、建一个默认团队。换端口：`PORT=9000 npx @xiechimon/cairn`，这时 Runner 要加 `--server http://127.0.0.1:9000`。

2. 在同一台机器的浏览器里打开 **[http://127.0.0.1:8787/app](http://127.0.0.1:8787/app)**。

3. 让浏览器登录：

   <Tabs syncKey="os">
   <TabItem label="Linux">
   服务端所在机器上的浏览器会通过本机回环自动登录，什么都不用粘贴。
   </TabItem>
   <TabItem label="macOS / Windows">
   这两个系统拿不到本机回环的对端证明，第一个浏览器会话要用 owner 令牌换一个配对码。第一次启动时令牌写在 `~/.cairn/token`（权限 0600）：

   ```sh
   curl -s -X POST -H "Authorization: Bearer $(cat ~/.cairn/token)" \
     http://127.0.0.1:8787/api/remote/pairing
   ```

   在浏览器的配对页输入返回的配对码。
   </TabItem>
   </Tabs>

</Steps>

界面跟随浏览器语言。首次向导依次显示 **接入模型** 和 **确认设置**（核对 Coordinator 模型，任务默认复用该模型）。按[接入模型](/zh-cn/docs/models/)操作后确认选择。独立的 npm 安装还要[连接 Runner](/zh-cn/docs/runner/) 并确认其在线。

macOS 和 Windows 的 npm 浏览器配对不是 owner 会话，目前不能添加模型连接或批准 Runner。按[上手指南](https://github.com/xiechimon/cairn/blob/main/docs/getting-started.md#run-the-server)用 owner-token API，或改用自带 owner 登录的桌面应用。浏览器配对成功不等于模型设置完成。

<Aside type="caution">
服务端只监听 `127.0.0.1`，非浏览器的客户端一律要带令牌。不要在没有令牌的情况下把它绑到公网地址；见下面的 [用 Docker 跑](#用-docker-跑) 和 [在手机上访问](#在手机上访问)。
</Aside>

## 数据放在哪

npm 默认都在 `~/.cairn` 下（设 `CAIRN_HOME` 可以换位置）：服务端有 `server/server.db` 和 `server/secretbox.key`；Runner 有 `machine.json`、`daemon.log` 和 `workspaces/`。桌面端 macOS 在 `~/Library/Application Support/@cairn/desktop`，Linux 在 `$XDG_CONFIG_HOME/@cairn/desktop`（默认 `~/.config/@cairn/desktop`）。**备份就是复制整个数据目录。** 只拷数据库没用，少了密钥文件解不开。

## 用 Docker 跑

只有服务端和网页应用做成了镜像；agent 还是通过你自己机器上的 Runner 干活。镜像绑定 `0.0.0.0`，所有状态放在 `/data`，没有令牌就拒绝启动：

```sh
docker build -t cairn .
docker run -d --name cairn -v cairn-data:/data \
  -e CAIRN_TOKEN="$(openssl rand -hex 32)" -p 8787:8787 cairn
```

在[仓库](https://github.com/xiechimon/cairn)的检出目录里构建。前面要有 TLS 终结，因为令牌放在请求头里。备份整个 `/data` 卷。

## 在手机上访问

在本机回环的服务端前面挂 [Tailscale Serve](https://github.com/xiechimon/cairn/blob/main/docs/deploy/tailscale-mobile.md)。这样 Cairn 只在你的私有 tailnet 里可达，不用公网地址；每台新设备仍要用设置里 `远程访问` 生成的一次性配对码登录。走 Serve 的 HTTPS 之后，iOS 还能把 Cairn 添加到主屏幕、收推送。

## 从源码构建

需要 Node.js 22.19 或更高，以及 pnpm（比如用 `corepack enable`）：

```sh
git clone https://github.com/xiechimon/cairn
cd cairn
pnpm install --frozen-lockfile --ignore-scripts
pnpm start
```

`pnpm start` 会构建网页并启动同源托管它的服务端。服务端和 Runner 的全部环境变量见 [configuration.md](https://github.com/xiechimon/cairn/blob/main/docs/configuration.md)。
