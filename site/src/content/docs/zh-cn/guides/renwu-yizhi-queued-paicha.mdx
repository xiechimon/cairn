在 Cairn 里看到有执行机显示**在线**，但任务却一直停在 **排队中（Queued）**，通常不是系统卡死，而是没有一台**同时满足全部硬约束**的在线执行机。先看任务旁边显示的排队原因提示，再按下面三项逐一核对即可解决。

## 常见卡住原因与排查表

| 排队提示方向 | 真正原因 | 解决办法 |
|---|---|---|
| **本地路径不可达 / 绑定机器离线** | 「本地文件夹」项目只能在那台登记路径的机器上跑 | 把那台执行机重新上线；若需多机接力，改用 GitHub 仓库形式创建项目 |
| **缺少目标运行时（如 Claude Code）** | 任务路由选了 Claude Code，但在线执行机未检测到 `claude` | 在执行机安装 `claude` 并确保在 `PATH` 中，重启执行机后去 **设置 → 执行机** 核对 |
| **模型连接缺失或已过期** | 所选服务商令牌失效或尚未完成设备码登录 | 到 **设置 → 模型** 重新验证或更新订阅令牌 / API key |

## 快速命令行诊断（独立 CLI Runner）

如果任务派往独立的命令行执行机，可以登录那台机器查看状态和实时日志：

```sh
cairn status
cairn doctor
cairn logs -f
```

如果是 Mac 桌面端内置执行机，打开 **设置 → 执行机** 与 **设置 → 模型** 核对在线状态与连接状态（更多见[常见问题](/zh-cn/docs/faq/)与[第一个任务](/zh-cn/docs/first-task/)）。
