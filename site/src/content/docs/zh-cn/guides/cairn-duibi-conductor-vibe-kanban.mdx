在 Mac 上用多个编码 Agent 并行干活时，开发者常会把 **Cairn**、**Conductor** 和 **Vibe Kanban** 放在一起对比。需要注意的是，截至 2026 年 11 月，[BloopAI/vibe-kanban](https://github.com/BloopAI/vibe-kanban) 仓库首页已经正式公告 **Vibe Kanban 即将停止维护（sunsetting）**；目前仍在持续演进的，主要是闭源商业化的 **Conductor** 与 Apache-2.0 开源的 **Cairn**。

## 三者核心能力对比（2026-11-27 实测核对）

| 对比维度 | Cairn | Conductor | Vibe Kanban |
|---|---|---|---|
| **开源与维护状态** | Apache-2.0 开源，持续活跃迭代 | 商业闭源产品（[conductor.build](https://www.conductor.build/docs)） | 已公告停止维护（Sunsetting） |
| **产品形态** | Mac 桌面应用优先 + 可选 Linux 进阶服务端 | Mac / 云端多工作区桌面环境 | 本地 `npx` 看板 Web 工具 |
| **核心工作流** | Coordinator 拆解派活 + 跨任务记忆 + 合并闸门 | 并行工作区 + 内置终端 / Diff 查看器 / Checks | 看板任务 + 10+ CLI 切换 + 内置网页预览 |
| **支持引擎与订阅** | 内置 pi（免装 CLI 跑 ChatGPT 订阅/API/中转）+ Claude Code | Claude Code、Codex、Cursor、OpenCode | Claude Code、Codex、Gemini 等 10+ CLI |
| **出门手机远程控制** | Tailscale Serve 私网 HTTPS + 微信 / Telegram / Slack | 桌面与云端工作区体系 | 仅面向本地浏览器开发预览 |

## 什么时候选 Conductor 更合适

如果你的日常主力包含 **Cursor** 或 **OpenCode**，并且更偏爱在桌面端直接逐行看 Diff、内置浏览器/终端并交互式推 PR，**Conductor** 提供了非常成熟的商业化工作区体验。

## 什么时候选 Cairn 更合适

如果你更看重 **Apache-2.0 全部源码可控**、希望把你的纠正写进长期记忆并演化成仓库检查、需要免装 Codex CLI 跑 ChatGPT 订阅或国内中转 API，或者想把 Mac mini 放家里、出门用手机和微信远程拍板，建议从 [Cairn Mac 桌面应用](/zh-cn/docs/install/) 开始。
