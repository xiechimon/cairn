在 Mac 上同时开多个 Claude Code 终端窗口最容易遇到“互相覆盖文件”和“分支乱掉”的问题。使用 **Cairn Mac 桌面应用**，你可以把多个需求直接发给同一个 Coordinator，它会为每个任务在 `~/.cairn/workspaces/<conversationId>` 各自拉出独立的 git worktree 与专属分支，并行改代码、跑测试互不冲突。

## 为什么手开多个终端容易打架

当两个 `claude` 会话共处同一个本地目录时，它们会同时读写同一份工作区和 `git status`，一旦一个任务刚改完文件、另一个任务执行 `git diff` 或测试，就会互相干扰。即便手动 `git worktree add`，你仍需要逐个终端盯着 `y/N` 权限确认并手动清理目录。

## Cairn 的并行隔离机制

1. **一次运行 = 一个独立 worktree：** 每次任务派发都在 Runner 专属的 `workspaces/` 隔离目录检出，主目录与 `main` 分支保持干净。
2. **统一队列与决策收口：** 多个任务在后台并发执行时，需要你拍板的选择集中到「需要你定的」卡片，不会静默卡在某个后台终端标签页。
3. **一次性接入订阅令牌：** 在一台电脑运行 `claude setup-token` 并将令牌填入 **设置 → 模型** 后，各 Runner 即可复用，前提是该执行机已安装 `claude` CLI（详见[接入模型](/zh-cn/docs/models/)）。

如果暂时不想单独装 `claude` CLI，也可以使用 Cairn 桌面端内置的 **pi** 引擎配合 ChatGPT 订阅或 API key 并行执行任务，也可参考 [Cairn 对比 Conductor 与 Vibe Kanban](/zh-cn/guides/cairn-duibi-conductor-vibe-kanban/)。
