## What does it cost?

Today, nothing. All code is Apache-2.0 with no feature gating; only a private, rotating holdout subset of the eval task set stays unpublished. There is no hosted service and no resold compute. You pay only for the model subscriptions or API keys you already use.

## Can my team share one Cairn?

No. Cairn is for one person: you run your own copy, and someone else who wants it runs theirs. For a tool a team shares, with shared channels, roles and billing, look at [Amp Spaces](https://ampcode.com/docs/spaces) or [Multica](https://github.com/multica-ai/multica).

## Is there a hosted version?

Not today. An official paid hosted service, Cairn Cloud, is planned and not available yet. Today Cairn runs locally via the Mac desktop app (or on your own servers via the advanced self-hosted path), and self-hosting stays free with full functionality. If you want a hosted service today, with nothing to install or keep running, it is not the right fit.

## Where do my code and credentials go?

They stay on your machines by default. Threads run directly on your Runners, each in its own git worktree under `~/.cairn/workspaces`. Provider keys and secrets you add are encrypted on your server. Model calls go from your machines to the providers you chose. For the full breakdown of local storage and what configured integrations or optional services send, see [privacy.md](https://github.com/xiechimon/cairn/blob/main/docs/privacy.md).

## Can it handle mail, calendar and job search?

Not yet. That is planned as a project with no repository, where agents read, sort and draft, and sending and submitting wait for you.

## The Coordinator does not answer

The home page shows the next setup step that is missing. Work through them in order:

1. In `Connect models`, complete the in-app ChatGPT subscription device login or add your own API key. A local Claude CLI login alone is not Cairn's subscription setup. See [Connect a model](/docs/models/).
2. In `Confirm settings`, check the Coordinator model (tasks default to it), then confirm. A fresh ChatGPT-only setup selects GPT-6.1 Sol with pi tasks. Existing rules can differ; inspect `Settings → Model`.
3. Check the Runner is online under `Settings → Runners`. Desktop starts one for you; an npm server needs a separate Runner. See [Connect a Runner](/docs/runner/).

## My Runner is online but tasks stay queued

Read the reason shown next to `Queued`. Common causes are a local-folder project bound to a different offline Runner, an optional runtime (such as Claude Code) not installed on the online Runner, or a missing/expired model connection for the selected model under `Settings → Model`. Run `cairn logs -f` on the Runner to see what the daemon is doing.

## My Runner went offline

A Runner started with `cairn start` ends when you log out or reboot. Run `cairn start` again, or install the user unit so it comes back by itself. Credentials are kept in `~/.cairn/machine.json`, so it needs no new approval.

## The enrollment link expired

Nobody approved the machine within 10 minutes. Run `cairn start` again for a new link.

## `cairn` runs the wrong program

Both `@xiechimon/cairn` and `@xiechimon/cairn-cli` install a `cairn` command, and the one installed last wins. Run the server with `npx @xiechimon/cairn` and keep only the CLI installed globally.

## Can I use it from my phone?

Yes. Put Tailscale Serve in front of the server, then sign the phone in with a one-time pairing code from `Remote access` in settings. The server never needs a public address. Steps are in [the Tailscale guide](https://github.com/xiechimon/cairn/blob/main/docs/deploy/tailscale-mobile.md).

## How do I back up or move Cairn?

Copy the whole `~/.cairn` directory, or the `/data` volume in Docker. The database and `secretbox.key` must stay together: secrets are encrypted with that key.
