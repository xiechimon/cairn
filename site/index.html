你写任务，agent 干活，你来把关。You write the tasks. Agents build. You gate.

Cairn 是自托管的多 agent 编排工作台：agent 在你自己的机器上领任务、写代码、互相审核，合并前必须过你这一关。Cairn is a self-hosted multi-agent workspace. Agents claim tasks, write code and review each other on your own machines, and nothing merges without your sign-off.

多 agent 分工Agents with roles

chief 只派活不写代码，coder 并行实现，reviewer 审改动，你只在计划和合并两处拍板。A chief only dispatches, coders build in parallel, a reviewer checks the diff, and you decide at the plan and the merge.

用自己开发自己Builds itself

Cairn 的新功能由 Cairn 里的 agent 领票、实现、审核、开 PR，跑在同一个闭环里。Cairn's own features are claimed, built, reviewed and shipped as PRs by agents running inside Cairn.

评测驱动，不微调模型Eval-driven, no fine-tuning

每次构建记下 harness 版本，用评测和轨迹数据改提示词、技能和路由；同一个错优先落成类型和测试。Every build records its harness version; evals and trajectories tune prompts, skills and routing, and repeat mistakes become types and tests.
